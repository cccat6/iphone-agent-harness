# 安装与使用教程

[English](README.md) · **简体中文** · [繁體中文](zh-Hant.md) · [日本語](ja.md) · [Русский](ru.md) · [Deutsch](de.md) · [Français](fr.md) · [Español](es.md) · [项目首页](../../README.md) · [打开 Harness](https://igent.cc/) · [架构图](../architecture/overview.md)

准备运行 iOS/iPadOS 27 或更新版本的 iPhone 或 iPad、支持的 ESP32 开发板、USB 电源、局域网 Wi-Fi，以及可用的 AI 账号或 API。在电脑 Chrome 或 Edge 中安装预编译固件，无需安装 Arduino、Xcode、本地编译环境，也不需要开发者账号。

日常使用时，手机和 ESP32 桥连接同一个普通 Wi-Fi。桥不需要插在手机上，供电后可以放在房间里蓝牙信号可达的位置。首次配网也可以在电脑上完成，手机无需连接桥的热点。

<a id="accessibility"></a>
## 1. 开启辅助触控

在手机打开 **设置 → 无障碍 → 触控 → 辅助触控**，开启辅助触控。ESP32 桥通过这个系统功能把蓝牙指针输入转换为界面操作。“全键盘控制”可以保持原来的设置；桥的 Home 按键和指针控制不要求开启它。

<a id="flash"></a>
## 2. 在网页上烧录 ESP32

1. 在电脑 Chrome 或 Edge 中打开[烧录页面](https://igent.cc/flash)。
2. 根据开发板上的芯片型号选择固件。页面只列出已经构建的版本。ESP32-C2 至少需要 **2 MB Flash**；表中其他芯片至少 **4 MB**。无需 PSRAM、屏幕或外接传感器。
3. 用支持数据传输的 USB 线把板子接到电脑，点击“选择 USB 设备并安装”，在浏览器选择框中选中这块板子的串口。
4. 等待写入和校验完成。如果开发板没有自动进入下载模式，可以按住 BOOT 接线或复位，松开 BOOT 后重试。
5. 点击“读取设备信息”，再次选择同一块板子。页面会显示首次设置用的 Wi-Fi 名称、密码，以及手机连接链接，留作下面使用。

USB 用于烧录、读取设置信息和供电。手机操作过程中只需要给板子供电，无需用线把板子接到手机。

安装器只显示一个 **ESP32-C2** 选项，自动选择 26 或 40 MHz 晶振镜像。2 MB 镜像为单应用分区，不含 OTA。C2 通过 **USB 转串口**连接（开发板常已集成），不是原生 USB CDC。**ESP32-C5** 镜像使用 80 MHz 闪存配置和原生 USB CDC。

<a id="wifi"></a>
## 3. 将桥连接到常用 Wi-Fi

新板子首次使用时做一次：

1. 在**电脑**上临时连接烧录页显示的 `iPhone-Harness-…` 设置热点，填写页面显示的密码。
2. 打开 `http://192.168.4.1`，填写家里或办公室的 Wi-Fi 名称和密码。所有支持的型号都可以使用 2.4 GHz 网络。
3. 等页面确认连接成功，再把电脑切回常用 Wi-Fi。
4. 手机继续使用同一个局域网 Wi-Fi，不用连接 ESP32 热点，也不用改用蜂窝网络访问模型。

Wi-Fi 信息保存在桥本地。以后通电后会自动连接，已经配好网的板子直接跳过这一步。桥在局域网中的管理页面是 `http://igent.local/settings`，可查看和修改页面提供的设备设置，包括本地名称。

<a id="bluetooth"></a>
## 4. 配对蓝牙输入桥

打开手机 **设置 → 蓝牙**，配对 **iPhone Agent Bridge**，并保持辅助触控开启。这里的蓝牙连接负责把输入送到 iOS；Harness 与桥之间的局域网连接负责把智能体的指令送到板子，两者是独立的连接。

如果固件更新改变了 HID 报告，先在系统蓝牙设置中忽略旧记录，再重新配对。正常刷新网页或切换模型不用重新配对。

<a id="open-harness"></a>
## 5. 打开 Web Harness

在手机 Safari 中打开 [igent.cc](https://igent.cc/)。兼容的 iPhone、iPad 会进入 Harness；电脑端显示主页、技能社区和固件烧录页面。不需要配套 iOS App、证书描述文件、Safari 扩展或开发者模式。

开始操作时，Safari 会请求共享屏幕。允许共享，并在运行时保持手机解锁。这是正常的系统录屏授权，不需要开启实验性局域网开关或做额外的网络授权绕行。停止共享会暂停当前任务；点击“继续”时，缺少共享就会再次请求。

<a id="models"></a>
## 6. 配置 API 或 ChatGPT 账号

打开 **设置 → 账号或 API → 添加**。可以保存多套接入，在会话底部的模型选择器中切换。

### API 端点与密钥

1. 选择 **OpenAI 兼容**或 **Anthropic 兼容**的接入方式。
2. 填写服务商的 API 端点、密钥和这个连接的名称。按表单提示填写服务根地址或 `/v1` 基础路径；受支持的完整操作地址也会由适配器归一化。
3. 点击“获取模型列表”，选择默认模型，也可以手动输入模型 ID。获取到的模型都会保留在会话选择器中。
4. 保存。手机操作需要选择能理解图片并调用工具的模型；支持推理强度的模型还可在选择器中调整。

密钥保存在当前浏览器，请求直接发送给所选服务商，不通过我们的页面托管服务中转。API 服务需要允许你所用网页来源的浏览器请求。

### ChatGPT 订阅账号

先在 ChatGPT 安全设置中开启设备码登录；工作区账号可能需要管理员开启。然后在 Harness 选择 ChatGPT／Codex 账号接入，开始设备码登录。打开表单提供的官方验证页，填写显示的设备码并完成登录，再回到 Harness 点击完成登录，获取模型并保存。这里使用订阅接入，而不是普通 OpenAI API Key；凭据保存在浏览器本地，由账号适配器续期。浏览器需要能访问官方登录服务，账号设置可参考 [OpenAI 官方设备码登录说明](https://learn.chatgpt.com/docs/auth#preferred-device-code-authentication-beta)。

<a id="bridge"></a>
## 7. 连接桥并按需测试输入

1. 从会话列表或会话中的桥状态进入“设备”。
2. 首次没有连接信息时，点击“获取桥的信息”，打开本地桥页面，再使用页面中的返回链接。这会导入板子的地址和公开 WebRTC 连接信息。电脑烧录页提供的手机连接链接也能导入这些信息。
3. 点击“连接 ESP32 桥”，需要时选择已经配对、输入就绪的手机。信息保存后，下次直接连接即可，不用重新配网。
4. 想检查键盘输入时，点击一次“开始输入测试”，保持页面和测试框在前台。桥会输入八位数字，网页收到后自动确认；新固件不强制要求通过这个测试才能使用。

“刷新”只读取状态。“桥已连接”“手机蓝牙已连接”“输入已就绪”是不同状态。如果输入仍在初始化，稍等后刷新即可。明确被限流拒绝的测试会显示倒计时，并可自动重试一次；执行结果未知的输入不会盲目重发。连接失败会直接显示状态和原因。

先试一个短任务，例如“打开时钟，设置一个 7:00 的闹钟”。按提示允许屏幕共享后切到目标 App，智能体会观察、操作并核对结果。任务完成后默认返回当前 Harness 会话；希望停留在目标 App 时，关闭 **设置 → 任务完成后 → 任务完成后返回 Harness**。

<a id="clipboard"></a>
## 8. 配置剪贴板快捷指令

1. 在手机打开[剪贴板教程](https://igent.cc/shortcuts/clipboard.html)，下载已签名的快捷指令。
2. 在苹果“快捷指令”中添加 **iPhone Agent Clipboard**，保留这个名称。
3. 在 Harness 连接桥。智能体准备好文字后，点击“用快捷指令复制”。如果 iOS 询问快捷指令是否可以访问本地桥地址，允许即可；这是快捷指令本身的权限提示。
4. 复制完成后回到 Harness。它会等待复制回执，检查目标 App 和输入框，再进行粘贴。

文字由网页分块送到桥，再通过一次本地 HTTP 响应交给快捷指令，桥不需要缓存全文。没有待复制内容时，单独运行快捷指令不会改变原剪贴板。不使用快捷指令时，也可以在网页前台选择“复制并继续”。

<a id="install-skills"></a>
## 9. 安装社区技能

在手机打开 **设置 → 技能 → 技能社区**，或进入[技能社区](https://igent.cc/skills)，阅读说明后点击“添加到本地”。内置技能和社区技能会一起显示，内置技能已经可以在本地使用。在已安装列表中可以开启或关闭各个技能。

刷新页面会更新内置技能，并检查未修改的社区技能是否有新版。开关选择和本地修改会保留；正在执行的任务继续使用开始时的版本，更新用于后续任务。社区下载项保持只读，并保留原作者。

<a id="authoring"></a>
## 10. 制作自己的技能

电脑端在[技能社区](https://igent.cc/skills)的“创作与发布”中选择“创建自己的技能”；手机端也可以从 **设置 → 技能 → 创建**进入。填写名称、小写英文短名、简介和 Markdown 操作说明，保存为本地草稿。

也可以直接和 Harness 聊天，让它创建或改进自己的技能。描述技能适用的任务、可用控件、操作步骤、截图中的成功标准，以及失败后应如何调整。内置技能和其他作者的社区技能保持只读。

归属由浏览器生成的签名身份确定，电脑和手机都可以使用，不依赖 iOS UID。换浏览器或设备前，导出技能文件和加密的“创作者身份”备份；在新浏览器恢复身份，再导入自己的技能文件，就能以同一作者继续编辑。

<a id="publish"></a>
## 11. 分享自己的技能

在社区页面对自己的草稿选择“发布到社区”；手机端也可以从技能分享面板进入。检查内容并确认发布，公开技能包会用本地创作者身份签名。以后修改自己的技能并再次发布，就会生成下一版本；其他用户刷新其安装副本时可获得更新。

欢迎在 [Issue](https://github.com/cccat6/iphone-agent-harness/issues) 中报告问题或提建议，在 [PR](https://github.com/cccat6/iphone-agent-harness/pulls) 中贡献代码、文档和翻译。自定义技能通过网站社区分享即可，不需要提交代码 PR。

## 会话与自行托管

点击列表标题，在“会话”和“已归档”之间切换。普通会话左滑可重命名或归档；归档项可重命名、取消归档或删除。历史消息随上滑逐页加载，新回复不会打断阅读，点击“回到最新”即可回到当前输出。

会话、保存的图片和凭据保存在当前浏览器。会话菜单可导出，设置中可导入；会话导出不含凭据。我们托管的服务提供页面和公开技能，选定的模型／MCP 数据直接发送到相应服务。你也可以[自行托管 Web Harness](../architecture/deployment.md)。
