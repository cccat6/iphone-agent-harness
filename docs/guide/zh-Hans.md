# 安装与使用教程

[English](README.md) · **简体中文** · [繁體中文](zh-Hant.md) · [日本語](ja.md) · [Русский](ru.md) · [Deutsch](de.md) · [Français](fr.md) · [Español](es.md) · [项目首页](../../README.md) · [打开 Harness](https://igent.cc/) · [架构图](../architecture/overview.md)

准备 iOS/iPadOS 27 或更新版本的 iPhone 或 iPad、ESP32 开发板、USB 电源、Wi-Fi，以及 AI 账号或 API 密钥。烧录固件时使用电脑上的 Chrome 或 Edge。

手机与桥连接同一 Wi-Fi。设置完成后，让桥保持供电，放在手机蓝牙信号可达的位置即可。

<a id="accessibility"></a>
## 1. 开启辅助触控

在手机打开 **设置 → 无障碍 → 触控 → 辅助触控**，开启辅助触控，让 ESP32 可以通过指针点按和拖动。

<a id="flash"></a>
## 2. 在网页上烧录 ESP32

1. 在电脑的 Chrome 或 Edge 打开[网页烧录器](https://igent.cc/flash)。
2. 选择开发板上标注的芯片。C2 至少需要 **2 MB 闪存**，其余型号使用至少 **4 MB 的标准 SPI 闪存**。
3. 用 USB 数据线连接开发板，点击 **选择 USB 设备并安装**，选中开发板后等待完成。
4. 点击 **读取设备信息**，选择同一块板，记下页面显示的配网 Wi-Fi 信息和手机连接链接。

若无法开始烧录，按住板上的 BOOT 键重新插入 USB，松开后再试。C2 的 26/40 MHz 版本由烧录器自动选择。设置完成后，给板子供电即可无线操作手机。

<a id="wifi"></a>
## 3. 将桥连接到常用 Wi-Fi

1. 电脑连接烧录器显示的 `iPhone-Harness-…` Wi-Fi，输入页面给出的密码。
2. 打开 `http://192.168.4.1`，填写家里或办公室的 Wi-Fi 名称与密码。使用 2.4 GHz 网络可兼容所有支持的芯片。
3. 桥连接成功后，让电脑回到原来的 Wi-Fi。手机也连接这个网络。

桥会记住网络，之后通电自动连接。只有首次使用或更换网络时才需要配网。以后可打开 `http://igent.local/settings` 修改桥的设置。

<a id="bluetooth"></a>
## 4. 配对蓝牙输入桥

在手机打开 **设置 → 蓝牙**，配对 **iPhone Agent Bridge**，并保持辅助触控开启。

蓝牙负责操作手机；Harness 还需要在第 7 步通过 Wi-Fi 连接桥。

<a id="open-harness"></a>
## 5. 打开 Web Harness

用 iPhone 或 iPad 的 Safari 打开 [igent.cc](https://igent.cc/)，即可进入 Harness。

让它操作手机时，同意屏幕共享并保持解锁，随后可以切换到其他 App。停止共享会暂停任务；回到 Harness 点击 **共享屏幕并继续**，重新共享后即可接着执行。

<a id="models"></a>
## 6. 配置 API 或 ChatGPT 账号

打开 **设置 → 账号或 API → 添加**。可以保存多套接入信息，并在会话里切换模型。

**使用 API 密钥**

1. 按服务商提供的接口选择 **OpenAI 兼容** 或 **Anthropic 兼容**。
2. 填写名称、API 端点和密钥。例如 `https://api.example.com/v1`；也可以粘贴所选接口对应的完整 `/chat/completions` 或 `/messages` 地址。
3. 点击 **获取模型列表**，选择默认模型，也可以手动输入模型名。列表中的其他模型仍然可以在会话里使用。
4. 保存。操作手机时，选择支持图片和工具调用的模型；模型提供推理强度选项时，可在模型选择器里调整。

**使用 ChatGPT 账号**

在 Harness 中选择“ChatGPT 订阅”，点击“继续使用 ChatGPT”，打开官方页面完成授权。随后浏览器会显示无法打开本机返回地址（`127.0.0.1`），这是正常现象。复制地址栏的完整网址，回到 Harness 粘贴到“返回地址”，再点击“完成登录”。随后从获取到的列表中选择模型并保存账号。登录凭据保存在当前浏览器，模型请求直接发送给 OpenAI。已有 Codex 连接会保留，新增的 ChatGPT 订阅使用独立账号。[OpenAI 授权说明](https://developers.openai.com/siwc/token-sharing-open-source/sign-in)。

账号信息和 API 密钥保存在当前浏览器中，请求直接发送给所选服务商。服务商的接口需要支持浏览器访问。

### 定位

在 **设置 → 定位** 中开启定位能力，默认关闭。开启后，只有智能体明确调用 `phone_get_location` 工具时才读取一次当前位置。首次调用由浏览器请求授权，结果提供给当前选定的模型。位置来自打开 Harness 的设备，即使未连接 ESP32、未共享屏幕也可使用。

<a id="bridge"></a>
## 7. 连接桥并按需测试输入

1. 在会话列表打开 **设备**，或点击会话中的桥连接状态。
2. 第一次连接时，点击 **获取桥信息**。在桥的页面点击返回链接，回到 Harness；也可以使用烧录器提供的手机连接链接。
3. 点击 **连接 ESP32 桥**，需要时选择已配对的手机。以后可直接使用保存好的连接。
4. 想检查键盘输入时，点击 **开始输入测试** 并留在当前页面。桥会输入 8 位数字，Harness 自动检查结果；此测试可以跳过。

一个 ESP32 桥支持两条独立的 Harness 连接。两台手机一起使用时，在各自网页选择对应手机，建议分别运行一次连接测试，确认绑定正确。

若手机尚未就绪，检查手机的蓝牙连接，稍等片刻后点击 **刷新**。

可以先试“打开时钟，设置早上 7 点的闹钟”，并在提示时允许屏幕共享。任务完成后默认回到当前会话；可在 **设置 → 任务完成后 → 返回 Harness** 中修改。

<a id="clipboard"></a>
## 8. 配置剪贴板快捷指令

1. 在手机打开[剪贴板教程](https://igent.cc/shortcuts/clipboard.html)，安装快捷指令。
2. 保留名称 **iPhone Agent Clipboard**。
3. 在 Harness 连接桥。需要复制文字时点击 **通过快捷指令复制**；如果系统询问是否允许访问桥，选择允许。
4. 复制完成后回到 Harness，继续粘贴到目标输入框。

长文本和多语言文字都可以使用。Harness 在前台时，也可以使用 **复制并继续**。

<a id="install-skills"></a>
## 9. 安装社区技能

打开 **设置 → 技能 → 社区**，或访问[技能社区](https://igent.cc/skills)。查看技能说明后，点击 **添加到本地**，之后可以在技能列表里开启或关闭。

内置技能已经安装。刷新网页时会检查技能更新，并保留你的开关设置；更新在下次任务中生效。

<a id="authoring"></a>
## 10. 制作自己的技能

电脑访问[技能社区](https://igent.cc/skills)，点击 **创建自己的技能**；手机打开 **设置 → 技能 → 创建**。填写名称、小写字母组成的简短标识、简介和操作说明，然后保存。

也可以直接让 Harness 编写或完善你自己的技能，说明什么时候使用、具体怎么做、如何检查结果。想参考社区技能进行改写时，请创建自己的技能，保留原作者的版本。

更换浏览器前，导出技能并备份 **创作者身份**；在新浏览器导入两者，就能继续以同一作者发布。

<a id="publish"></a>
## 11. 分享自己的技能

打开自己创作的技能，在社区页面点击 **发布**，或在手机点击 **发布到社区**。检查内容后确认即可。以后修改并再次发布，就会更新这个技能。

其他用户可以在社区找到它并添加到自己的 Harness。软件问题和功能建议请[提交 Issue](https://github.com/cccat6/iphone-agent-harness/issues)，代码和文档改进欢迎[提交 PR](https://github.com/cccat6/iphone-agent-harness/pulls)。

## 管理会话

点击会话列表的标题，可切换 **会话** 与 **已归档**。左滑会话可以重命名、归档；在归档列表中可以恢复或删除。向上滚动阅读历史，点击 **回到最新** 返回最新消息。

在会话菜单中导出文件，在设置中导入。文件包含消息和图片；账号信息与密钥单独保存在浏览器中。
