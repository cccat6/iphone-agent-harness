# 安裝與使用教學

[English](README.md) · [简体中文](zh-Hans.md) · **繁體中文** · [日本語](ja.md) · [Русский](ru.md) · [Deutsch](de.md) · [Français](fr.md) · [Español](es.md) · [專案首頁](../../README.md) · [開啟 Harness](https://igent.cc/) · [架構圖](../architecture/overview.md)

準備 iOS/iPadOS 27 或更新版本的 iPhone 或 iPad、ESP32 開發板、USB 電源、Wi-Fi，以及 AI 帳號或 API 金鑰。燒錄時使用電腦上的 Chrome 或 Edge。

手機與橋連接同一 Wi-Fi。設定後讓橋保持供電，放在手機藍牙訊號可達的位置即可。

<a id="accessibility"></a>
## 1. 啟用輔助觸控

在手機開啟 **設定 → 輔助使用 → 觸控 → 輔助觸控**，啟用後 ESP32 就能透過指標點按與拖移。

<a id="flash"></a>
## 2. 在瀏覽器安裝 ESP32 韌體

1. 用電腦 Chrome 或 Edge 開啟[網頁燒錄器](https://igent.cc/flash)。
2. 選擇開發板上標示的晶片。C2 至少需要 **2 MB 快閃記憶體**，其餘型號使用至少 **4 MB 的標準 SPI 快閃記憶體**。
3. 用 USB 資料線連接開發板，點擊 **選擇 USB 裝置並安裝**，選取開發板後等待完成。
4. 點擊 **讀取裝置資訊**，選取同一塊板，保留頁面顯示的設定 Wi-Fi 資訊與手機連線連結。

若無法開始燒錄，按住板上的 BOOT 鍵重新接上 USB，再放開重試。C2 的 26/40 MHz 版本會自動選擇。設定完成後，為板子供電即可無線操作手機。

<a id="wifi"></a>
## 3. 讓橋加入平常的 Wi-Fi

1. 電腦連上燒錄器顯示的 `iPhone-Harness-…` Wi-Fi，輸入畫面提供的密碼。
2. 開啟 `http://192.168.4.1`，填入平常使用的 Wi-Fi 名稱與密碼。2.4 GHz 網路可相容所有支援的晶片。
3. 橋連線成功後，讓電腦回到原來的 Wi-Fi，手機也連上同一網路。

橋會記住網路，之後通電自動連線。只有首次使用或換網路才需要設定。日後可開啟 `http://igent.local/settings` 修改橋的設定。

<a id="bluetooth"></a>
## 4. 配對藍牙輸入橋

在手機開啟 **設定 → 藍牙**，配對 **iPhone Agent Bridge**，並保持輔助觸控啟用。

藍牙負責操作手機；Harness 還需在第 7 步透過 Wi-Fi 連接橋。

<a id="open-harness"></a>
## 5. 開啟 Web Harness

用 iPhone 或 iPad 的 Safari 開啟 [igent.cc](https://igent.cc/)，即可進入 Harness。

要求它操作手機時，同意畫面共享並保持解鎖，之後可切換到其他 App。停止共享會暫停任務；回到 Harness 點擊 **共享螢幕並繼續**，重新共享即可接著執行。

<a id="models"></a>
## 6. 設定 API 或 ChatGPT 帳號

開啟 **設定 → 帳號或 API → 新增**。可以保存多組設定，並在會話中切換模型。

**使用 API 金鑰**

1. 依服務商提供的介面選擇 **OpenAI 相容** 或 **Anthropic 相容**。
2. 填寫名稱、API 端點與金鑰，例如 `https://api.example.com/v1`；也可貼上所選介面對應的完整 `/chat/completions` 或 `/messages` 位址。
3. 點擊 **取得模型清單**，選擇預設模型或手動輸入名稱。清單中的其他模型仍可在會話中選擇。
4. 儲存。操作手機時，選擇支援圖片與工具呼叫的模型；模型提供推理強度選項時，可在模型選擇器調整。

**使用 ChatGPT 帳號**

在 Harness 選擇「ChatGPT 訂閱」，點選「繼續使用 ChatGPT」，開啟官方頁面完成授權。接著瀏覽器會顯示無法開啟本機返回位址（`127.0.0.1`），這是正常情況。複製網址列的完整網址，回到 Harness 貼入「返回位址」，再點選「完成登入」。接著從取得的清單選擇模型並儲存帳號。登入憑證保存在目前瀏覽器。現有 Codex 連線會保留，新增的 ChatGPT 訂閱使用獨立帳號。[OpenAI 授權說明](https://developers.openai.com/siwc/token-sharing-open-source/sign-in)。

對話、截圖與憑證持續儲存在瀏覽器。一般 API 請求直接傳給服務商。ChatGPT 訂閱因瀏覽器跨來源限制，透過專案提供或你自行架設的無狀態轉送服務通信：選定內容、圖片、模型輸出及短期存取權杖會經過該服務。轉送程式不持續儲存這些資料，也不記錄請求本文或憑證。登入與權杖更新仍由瀏覽器直連 OpenAI，更新權杖及 ID 權杖不經轉送。MCP 請求傳至你設定的伺服器；只有主動發布的技能會進入社群。

ChatGPT 訂閱的進階設定 **進階連線設定 → 自建轉送位址** 預設為 `https://igent.cc/api/openai`，也可填入自行架設服務的網址前綴。儲存帳號不必先取得模型清單，之後可再取得。

只架設轉送服務時，在 `wrangler.relay.jsonc` 將 `ALLOWED_ORIGINS` 設為網頁來源（多個來源以逗號分隔），執行 `npx wrangler deploy --config wrangler.relay.jsonc`，再將部署網址加上 `/api/openai` 填入 **進階連線設定 → 自建轉送位址**。服務只提供 `GET /api/openai/models` 與 `POST /api/openai/responses`，不需 OpenAI 金鑰、資料庫或 KV，也可搭配官方託管的 Harness。 自建轉送服務預設在 `aws:us-east-1` 執行，可依上游服務支援的區域調整設定。

### 定位

在 **設定 → 定位** 中開啟定位時，瀏覽器立即要求取得一次位置，方便你當場完成授權。之後，智慧體在任務需要時呼叫 `phone_get_location`，將新取得的位置提供給目前模型。位置來自開啟 Harness 的裝置。

<a id="bridge"></a>
## 7. 連接橋並依需要測試輸入

1. 從會話清單開啟 **裝置**，或點擊會話中的橋連線狀態。
2. 首次使用時點擊 **取得橋資訊**。在橋的頁面點擊返回連結，回到 Harness；也可使用燒錄器提供的手機連線連結。
3. 點擊 **連接 ESP32 橋**，需要時選擇已配對手機。之後可使用已儲存的連線。
4. 如需檢查輸入，點擊 **開始輸入測試** 並停留在此頁。橋會輸入 8 位數字，Harness 自動檢查；也可以略過測試。

一個 ESP32 橋接器支援兩條獨立的 Harness 連線。兩台手機一起使用時，在各自網頁選擇對應手機，建議分別執行一次連線測試，確認綁定正確。

若手機尚未就緒，檢查藍牙連線，稍等後點擊 **重新整理**。

可以先試「開啟時鐘，設定早上 7 點的鬧鐘」，並在提示時允許螢幕共享。在 **設定 → 返回 Harness** 中，可分別選擇 **任務完成後** 和 **需要我處理時**，預設皆開啟。等待回答、確認或需要你處理問題時，Agent 會返回目前對話，保留問題等你回應。

### 上下文用量

點選輸入區左側的圓環，查看已用 token、剩餘 token 與模型視窗容量；估算值會標示 ≈。點選 **立即壓縮**，將較早的上下文整理成後續請求使用的摘要，原始聊天記錄保留。

<a id="clipboard"></a>
## 8. 設定剪貼簿快捷指令

1. 用手機開啟[剪貼簿教學](https://igent.cc/shortcuts/clipboard.html)，安裝捷徑。
2. 保留名稱 **iPhone Agent Clipboard**。
3. 在 Harness 連接橋。文字準備好後點擊 **透過捷徑複製**；若系統詢問是否允許存取橋，選擇允許。
4. 複製後回到 Harness，繼續貼上到目標欄位。

長文字與多種語言都適用。Harness 在前景時也可使用 **複製並繼續**。

<a id="install-skills"></a>
## 9. 安裝社群技能

開啟 **設定 → 技能 → 社群**，或造訪[技能社群](https://igent.cc/skills)。閱讀技能說明後點擊 **加入本機**，再於技能清單啟用或停用。

內建技能已安裝。重新整理網頁時會檢查更新，保留你的啟用選擇；更新於下次任務生效。

<a id="authoring"></a>
## 10. 製作與改善自己的技能

電腦造訪[技能社群](https://igent.cc/skills)，選擇 **建立自己的技能**；手機則開啟 **設定 → 技能 → 建立**。填寫名稱、小寫字母組成的簡短識別名稱、簡介及操作說明，然後儲存。

也可請 Harness 編寫或改善自己的技能，說明使用時機、操作步驟與檢查結果的方法。若要改寫社群技能，請建立自己的技能，保留原作者版本。

更換瀏覽器前，匯出技能並備份 **創作者身分**。在新瀏覽器匯入兩者，即可繼續以同一作者發布。

<a id="publish"></a>
## 11. 分享技能

開啟自己製作的技能，在社群頁面選擇 **發布**，或在手機選擇 **發布到社群**。確認內容後發布；修改後再次發布就會更新技能。

其他使用者可在社群找到它並加入 Harness。軟體問題與建議請[提交 Issue](https://github.com/cccat6/iphone-agent-harness/issues)，程式或文件改進歡迎[提交 PR](https://github.com/cccat6/iphone-agent-harness/pulls)。

## 管理會話

點擊會話清單標題，切換 **會話** 與 **已封存**。左滑可重新命名或封存；在封存清單可還原或刪除。向上捲動閱讀歷史，點擊 **回到最新** 返回最新訊息。

在會話選單匯出檔案，再於設定匯入。檔案包含訊息與圖片；帳號資訊與金鑰另存於瀏覽器。
