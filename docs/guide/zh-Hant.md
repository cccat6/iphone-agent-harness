# 安裝與使用教學

[English](README.md) · [简体中文](zh-Hans.md) · **繁體中文** · [日本語](ja.md) · [Русский](ru.md) · [Deutsch](de.md) · [Français](fr.md) · [Español](es.md) · [專案首頁](../../README.md) · [開啟 Harness](https://igent.cc/) · [架構圖](../architecture/overview.md)

準備執行 iOS/iPadOS 27 或更新版本的 iPhone 或 iPad、支援的 ESP32 開發板、USB 電源、區域網路 Wi-Fi，以及可用的 AI 帳號或 API。在電腦 Chrome 或 Edge 安裝預編譯韌體，不需 Arduino、Xcode、本機編譯環境或開發者帳號。

日常使用時，手機與橋連接同一個普通 Wi-Fi。橋不需插在手機上，供電後可放在藍牙訊號可達的位置。首次配網也由電腦完成，手機不必加入橋的設定熱點。

<a id="accessibility"></a>
## 1. 啟用輔助觸控

在手機開啟 **設定 → 輔助使用 → 觸控 → 輔助觸控**。橋透過此系統功能，將藍牙指標輸入轉為介面操作。「完整鍵盤操控」可維持原來設定；橋的 Home 動作和指標控制不要求開啟它。

<a id="flash"></a>
## 2. 在瀏覽器安裝 ESP32 韌體

1. 在電腦 Chrome 或 Edge 開啟[燒錄頁面](https://igent.cc/flash)。
2. 依開發板上標示的晶片選擇設定檔。安裝器只列出已建置的版本。ESP32-C2 至少需 **2 MB Flash**；表中其他晶片至少 **4 MB**。不需 PSRAM、螢幕或外接感測器。
3. 使用可傳資料的 USB 線接到電腦，選擇「選擇 USB 裝置並安裝」，在瀏覽器串列埠選擇器選中該板。
4. 等待安裝與驗證完成。若無法自動進入下載模式，可按住 BOOT 接線或重設，鬆開後重試。
5. 選擇「讀取裝置資訊」，再選同一塊板。頁面顯示設定 Wi-Fi 的名稱、密碼與手機連結，請保留供後續使用。

USB 用於安裝韌體、讀取設定與供電。操作手機時只需電源供應器或其他 USB 電源，不需手機與板子之間的線纜。

安裝器只顯示一個 **ESP32-C2** 選項，會自動選擇 26 或 40 MHz 晶振映像。2 MB 映像採單應用分割區，不含 OTA。C2 透過 **USB 轉串列埠**連接（開發板常已整合），不是原生 USB CDC。**ESP32-C5** 映像使用 80 MHz 快閃記憶體設定和原生 USB CDC。

<a id="wifi"></a>
## 3. 讓橋加入平常的 Wi-Fi

新板子首次使用時完成一次：

1. 在**電腦**暫時加入安裝器顯示的 `iPhone-Harness-…` 設定 Wi-Fi，輸入頁面提供的密碼。
2. 開啟 `http://192.168.4.1`，輸入家中或辦公室的 Wi-Fi 名稱與密碼。所有支援型號都可使用 2.4 GHz 網路。
3. 等頁面確認連線成功，再讓電腦切回平常的 Wi-Fi。
4. 手機繼續留在同一區域網路，不需使用板子的熱點，也不需改用行動數據連接模型。

橋會將網路資訊儲存在本機，下次通電後重新連線。已設定好的板子可跳過此步。`http://igent.local/settings` 是區域網路管理頁，可使用頁面提供的裝置設定，例如修改本機名稱。

<a id="bluetooth"></a>
## 4. 配對藍牙輸入橋

在手機 **設定 → 藍牙** 配對 **iPhone Agent Bridge**，並保持輔助觸控啟用。系統藍牙連線把輸入交給 iOS；瀏覽器與橋之間的網路連線把 Agent 指令交給板子，兩者是獨立連線。

韌體更新若改變 HID 報告，請在系統藍牙設定忘記舊記錄，再重新配對。一般重新整理網頁或切換模型不需重新配對。

<a id="open-harness"></a>
## 5. 開啟 Web Harness

在手機 Safari 開啟 [igent.cc](https://igent.cc/)。支援的 iPhone/iPad 進入 Harness；電腦顯示首頁、技能社群與韌體安裝器。不需配套 iOS App、憑證描述檔、Safari 延伸功能或開發者模式。

開始操作時，Safari 會要求共享畫面。允許後保持手機解鎖。這是一般 iOS 畫面共享提示，不需開啟實驗性區域網路旗標或另外繞行網路授權。結束共享會暫停任務；按「繼續」時，若未共享便會重新要求。

<a id="models"></a>
## 6. 設定 API 或 ChatGPT 帳號

開啟 **設定 → 帳號或 API → 新增**。可保留多個連線，並由會話的模型選擇器切換。

### API 端點與金鑰

1. 選擇 **OpenAI 相容**或 **Anthropic 相容** API。
2. 輸入服務商端點、金鑰與連線名稱。依表單提示使用服務根網址或 `/v1` 基礎路徑；支援的完整操作網址也會由適配器正規化。
3. 選擇「取得模型」。由清單選預設模型，或手動輸入模型 ID。全部取得的模型仍保留在會話選擇器中。
4. 儲存。手機任務應選可理解圖片且能呼叫工具的模型；若支援推理強度，可在選擇器調整。

金鑰儲存在目前瀏覽器，請求直接送到所選服務商，不經網站主機中繼。服務商須允許來自所用網站的瀏覽器請求。

### ChatGPT 訂閱帳號

先在 ChatGPT 安全設定啟用裝置碼登入；受管理工作區可能需要管理員開啟。接著在 Harness 選 ChatGPT/Codex 帳號，啟動裝置碼登入，開啟表單提供的官方驗證頁，輸入顯示的代碼並完成登入。回到 Harness 按完成按鈕，取得模型並儲存連線。憑據保留在本機，由帳號適配器更新。這是訂閱連線，不是一般 OpenAI API 金鑰；瀏覽器必須能存取官方登入服務。參考 [OpenAI 裝置碼驗證說明](https://learn.chatgpt.com/docs/auth#preferred-device-code-authentication-beta)。

<a id="bridge"></a>
## 7. 連接橋並依需要測試輸入

1. 從會話列表或會話中的橋狀態開啟「裝置」。
2. 尚未儲存連線資訊時，選「取得橋的資訊」，開啟本機橋頁面，再使用返回連結。這會匯入板子地址與公開 WebRTC 資訊；安裝器的手機連結也能提供相同資訊。
3. 選「連接 ESP32 橋」，必要時選取已配對、輸入就緒的手機。資訊保存後，下次直接連線，不需再配網。
4. 若想確認原生鍵盤輸入，按一次「開始輸入測試」，讓頁面與測試框保持前景。橋會輸入八位數字，瀏覽器自動確認。此測試在目前韌體是選用項目。

「重新整理」只讀取狀態。「橋已連線」「手機藍牙已連線」「輸入已就緒」是不同狀態。仍初始化時稍候再重新整理。明確受到限流的測試會顯示倒數，並可重試一次；實體結果未知的輸入不會盲目重送。失敗時會顯示狀態與原因。

先試短任務，例如「開啟時鐘，設定 7:00 的鬧鐘」。依提示共享後切到目標 App，Agent 會觀察、操作、核對。預設完成後回到此 Harness 會話；若希望留在目標 App，關閉 **設定 → 任務完成 → 返回 Harness**。

<a id="clipboard"></a>
## 8. 設定剪貼簿快捷指令

1. 在手機開啟[剪貼簿教學](https://igent.cc/shortcuts/clipboard.html)，下載已簽署的快捷指令。
2. 在 Apple「捷徑」App 加入 **iPhone Agent Clipboard**，保留完整名稱。
3. 在 Harness 連接橋。Agent 備妥文字後，選「用快捷指令複製」。若 iOS 詢問是否允許捷徑存取本機橋網址，請允許；這是捷徑自己的權限提示。
4. 複製後回到 Harness。它會等候複製回執，檢查目標 App 與輸入欄，再貼上。

瀏覽器分塊傳文字給橋，再透過一次本機 HTTP 回應交給捷徑，橋不需暫存全文。無待處理工作時，執行捷徑不回傳文字，也不改變剪貼簿。未使用捷徑也可在網頁前景按「複製並繼續」。

<a id="install-skills"></a>
## 9. 安裝社群技能

在手機開啟 **設定 → 技能 → 社群**，或前往[技能社群](https://igent.cc/skills)。閱讀內容後選「加入本機」。內建技能與社群發布一起列出，且已可本機使用；在已安裝列表可啟用或停用。

重新整理會更新內建技能，並檢查未修改的社群安裝是否有新版。啟用選擇與本機修改保留；目前任務仍用開始時版本，更新用於之後任務。下載的社群技能唯讀並保留原作者。

<a id="authoring"></a>
## 10. 製作與改善自己的技能

電腦開啟[技能頁](https://igent.cc/skills)，在「創作與發布」選「建立自己的技能」；手機可用 **設定 → 技能 → 建立**。填名稱、小寫英文短名、簡介與 Markdown 指示，再儲存本機草稿。

也可請 Harness 建立或改善自己的技能。說明目標、適用情境、可用控件、成功畫面與失敗後調整方法。社群下載及內建技能仍唯讀。

歸屬來自瀏覽器產生的簽署身分，電腦與 iOS 都可用，不依賴 iOS UID。換瀏覽器或裝置前，匯出技能檔與加密「創作者身分」備份。在新瀏覽器恢復身分並匯入自有技能檔，即可用同一作者繼續編輯。

<a id="publish"></a>
## 11. 分享技能

社群頁對自有草稿選「發布」；手機可開技能分享面板，再選「發布到社群」。檢查內容後確認，公開包由本機作者身分簽署。修改後再次發布會建立下一版本，其他使用者的安裝副本重新整理時可更新。

歡迎用 [Issues](https://github.com/cccat6/iphone-agent-harness/issues) 回報問題與建議，用 [PR](https://github.com/cccat6/iphone-agent-harness/pulls) 貢獻程式碼、文件與翻譯。自訂技能透過網站社群分享，不需程式碼 PR。

## 會話與自行託管

點列表標題切換「會話」與「封存」。普通列左滑可改名／封存；封存列可改名／還原／刪除。向上捲動載入舊訊息，新回覆保留閱讀位置，點「最新訊息」回到目前輸出。

會話、已存圖片與憑據留在目前瀏覽器。會話選單可匯出，設定可匯入，匯出不含憑據。網站主機供應網頁與公開技能，選定模型/MCP 資料直接送至那些服務。也可[自行託管 Web Harness](../architecture/deployment.md)。
