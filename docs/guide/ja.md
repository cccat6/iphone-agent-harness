# セットアップと日常の使い方

[English](README.md) · [简体中文](zh-Hans.md) · [繁體中文](zh-Hant.md) · **日本語** · [Русский](ru.md) · [Deutsch](de.md) · [Français](fr.md) · [Español](es.md) · [プロジェクト](../../README.md) · [Harnessを開く](https://igent.cc/) · [構成図](../architecture/overview.md)

iOS/iPadOS 27以降のiPhoneまたはiPad、ESP32ボード、USB電源、Wi-Fi、AIアカウントまたはAPIキーを用意します。書き込みにはPCのChromeまたはEdgeを使います。

iPhoneとブリッジを同じWi-Fiにつなぎます。設定後は、iPhoneのBluetoothが届く場所でブリッジに給電しておきます。

<a id="accessibility"></a>
## 1. AssistiveTouchを有効にする

iPhoneの **設定 → アクセシビリティ → タッチ → AssistiveTouch** をオンにします。これでESP32のポインタによるタップやドラッグが使えます。

<a id="flash"></a>
## 2. ブラウザーからESP32ファームウェアを導入する

1. PCのChromeまたはEdgeで[ブラウザー書き込み](https://igent.cc/flash)を開きます。
2. ボードに記載されたチップを選びます。C2は **2 MB以上**、ほかの掲載チップは **4 MB以上の標準SPIフラッシュ**が必要です。
3. USBデータケーブルでボードを接続し、**USBデバイスを選んでインストール**から対象を選びます。完了まで待ちます。
4. **デバイス情報を読む**で同じボードを選び、設定用Wi-Fiの情報と電話用接続リンクを控えます。

書き込みが始まらない場合は、BOOTボタンを押したままUSBを接続し直し、放して再試行してください。C2の26/40 MHz版は自動選択されます。設定後は給電するだけで、iPhoneをワイヤレスで操作できます。

<a id="wifi"></a>
## 3. ブリッジを普段のWi-Fiにつなぐ

1. PCで、インストーラーに表示された `iPhone-Harness-…` Wi-Fiに接続します。パスワードも同じ画面にあります。
2. `http://192.168.4.1` を開き、普段のWi-Fi名とパスワードを入力します。2.4 GHzならすべての対応チップで使えます。
3. 接続が完了したらPCを普段のWi-Fiに戻し、iPhoneも同じネットワークにつなぎます。

ブリッジは設定を保存し、次回から電源投入時に再接続します。設定が必要なのは初回とネットワーク変更時だけです。後から `http://igent.local/settings` で設定を変更できます。

<a id="bluetooth"></a>
## 4. Bluetooth入力ブリッジをペアリングする

iPhoneの **設定 → Bluetooth** で **iPhone Agent Bridge** をペアリングします。AssistiveTouchはオンにしておきます。

BluetoothはiPhoneの操作に使います。HarnessからブリッジへのWi-Fi接続は手順7で行います。

<a id="open-harness"></a>
## 5. Web Harnessを開く

iPhoneまたはiPadのSafariで [igent.cc](https://igent.cc/) を開くと、Harnessが表示されます。

操作を依頼したら画面共有を許可し、ロックを解除したままにします。その後は別のアプリに切り替えられます。画面共有を止めるとタスクは一時停止します。Harnessで **画面共有して続行** を押すと再共有して続けられます。

<a id="models"></a>
## 6. APIまたはChatGPTアカウントを設定する

**設定 → アカウントまたはAPI → 追加** を開きます。複数の接続を保存し、会話でモデルを切り替えられます。

**APIキーを使う**

1. 提供元に合わせて **OpenAI互換** または **Anthropic互換** を選びます。
2. 名前、APIエンドポイント、キーを入力します。例は `https://api.example.com/v1` です。選んだAPIに対応する `/chat/completions`、`/messages` まで含むURLも入力できます。
3. **モデル一覧を取得**し、既定モデルを選ぶか名前を入力します。ほかのモデルも会話から選べます。
4. 保存します。iPhone操作には画像とツール呼び出しに対応したモデルを選びます。対応モデルでは推論の強さも調整できます。

**ChatGPTアカウントを使う**

Harnessで「ChatGPT サブスクリプション」を選び、「ChatGPT で続行」から公式ページを開いてアクセスを許可します。その後、ブラウザーはローカルの戻り先（`127.0.0.1`）を開けないと表示しますが、これは正常です。アドレスバーのURL全体をコピーし、Harnessに戻って「戻り先のアドレス」に貼り付け、「ログインを完了」を選んでください。取得した一覧からモデルを選んでアカウントを保存します。認証情報はこのブラウザーに保存され、モデルへのリクエストはOpenAIへ直接送信されます。既存のCodex接続は保持され、ChatGPTサブスクリプションは別のアカウントとして追加されます。[OpenAIの認証手順](https://developers.openai.com/siwc/token-sharing-open-source/sign-in)。

ログイン情報とキーはこのブラウザーに保存されます。リクエストは選んだ提供元へ直接送られるため、提供元がブラウザーからのアクセスに対応している必要があります。

### 位置情報

**設定 → 位置情報** で有効にできます。初期設定はオフです。有効にしても、エージェントが `phone_get_location` を明示的に呼び出したときだけ、一度位置を取得します。初回はブラウザーが許可を求め、結果は選択中のモデルに渡されます。Harnessを開いている端末の位置を取得するため、ESP32への接続や画面共有を開始していなくても使えます。

<a id="bridge"></a>
## 7. ブリッジを接続し、必要なら入力をテストする

1. 会話一覧から **デバイス** を開くか、会話内の接続状態を押します。
2. 初回は **ブリッジ情報を取得** を押し、開いたブリッジのページの戻るリンクからHarnessへ戻ります。インストーラーの電話用リンクも使えます。
3. **ESP32ブリッジに接続** を押し、求められたらペアリング済みの電話を選びます。次回からは保存した接続を使えます。
4. 入力を確認したい場合は **入力テストを開始** を押し、この画面に留まります。8桁の数字が入力され、結果を自動確認します。テストは省略できます。

一つのブリッジに二つのHarnessを独立して接続できます。二台の電話で使う場合は、それぞれの画面で対応する電話を選び、任意の入力テストで組み合わせを確認してください。

電話が準備完了にならない場合はBluetooth接続を確認し、少し待って **更新** を押してください。

「時計を開いて朝7時のアラームを設定して」と依頼してみましょう。画面共有を許可すると実行されます。完了後は会話に戻ります。**設定 → タスク完了 → Harnessに戻る** で変更できます。

<a id="clipboard"></a>
## 8. ショートカットでコピーする

1. iPhoneで[クリップボードガイド](https://igent.cc/shortcuts/clipboard.html)を開き、ショートカットを追加します。
2. 名前は **iPhone Agent Clipboard** のままにします。
3. Harnessでブリッジを接続し、テキストの準備後に **ショートカットでコピー** を押します。接続先へのアクセスを求められたら許可します。
4. コピー後にHarnessへ戻ると、目的の入力欄へ貼り付けを続けます。

長文や複数の言語に使えます。Harnessを表示中なら **コピーして続行** も使えます。

<a id="install-skills"></a>
## 9. コミュニティスキルを追加する

**設定 → スキル → コミュニティ**、または[スキルコミュニティ](https://igent.cc/skills)を開きます。説明を読み、**ローカルに追加**を押します。スキル一覧で有効・無効を切り替えられます。

内蔵スキルは追加済みです。ページを更新するとスキルの更新を確認し、有効・無効の設定を維持します。新しい版は次のタスクから使われます。

<a id="authoring"></a>
## 10. 自分のスキルを作成・改善する

PCでは[スキル](https://igent.cc/skills)の **自分のスキルを作成**、iPhoneでは **設定 → スキル → 作成** を開きます。名前、小文字の短い識別名、説明、手順を書いて保存します。

Harnessに自作スキルの作成・改善を頼むこともできます。使う場面、操作手順、結果の確かめ方を伝えてください。コミュニティのスキルを参考にする場合は、元の作者の版を残して自分のスキルを作成します。

ブラウザーを変える前にスキルと **作者ID** をバックアップします。新しいブラウザーに両方を読み込むと、同じ作者として公開を続けられます。

<a id="publish"></a>
## 11. スキルを共有する

自作スキルを開き、コミュニティページの **公開**、またはiPhoneの **コミュニティに公開** を押します。内容を確認して公開します。編集して再度公開すると更新版になります。

ほかの利用者はコミュニティから追加できます。不具合や提案は[Issue](https://github.com/cccat6/iphone-agent-harness/issues)、コードや文書の改善は[プルリクエスト](https://github.com/cccat6/iphone-agent-harness/pulls)へどうぞ。

## 会話を管理する

一覧の見出しを押すと **会話** と **アーカイブ** を切り替えられます。会話をスワイプして名前変更やアーカイブ、アーカイブ内では復元や削除ができます。上へスクロールして履歴を読み、**最新** で新しい返信に戻ります。

会話メニューからファイルを書き出し、設定から読み込めます。ファイルにはメッセージと画像が含まれます。アカウント情報とキーはブラウザーに別途保存されます。
