# セットアップと日常の使い方

[English](README.md) · [简体中文](zh-Hans.md) · [繁體中文](zh-Hant.md) · **日本語** · [Русский](ru.md) · [Deutsch](de.md) · [Français](fr.md) · [Español](es.md) · [プロジェクト](../../README.md) · [Harnessを開く](https://igent.cc/) · [構成図](../architecture/overview.md)

iOS/iPadOS 27以降のiPhone/iPad、対応ESP32ボード、USB電源、ローカルWi-Fi、対応AIアカウントまたはAPIを用意します。ファームウェアの導入はPCのChrome/Edgeで行います。ビルド済みインストーラーにArduino、Xcode、開発者アカウント、ローカルコンパイラーは不要です。

日常の利用では電話とブリッジを普段の同じWi-Fiに接続します。ボードを電話に挿す必要はなく、Bluetoothの届く場所で給電するだけです。初回のネットワーク設定もPCで行えば、電話をボードの設定用ホットスポットに接続する必要はありません。

<a id="accessibility"></a>
## 1. AssistiveTouchを有効にする

電話の **設定 → アクセシビリティ → タッチ → AssistiveTouch** を有効にします。このシステム機能を通じ、ブリッジのBluetoothポインター入力がアプリ操作になります。フルキーボードアクセスは現在の設定のままで構いません。Home操作やポインター制御の必須条件ではありません。

<a id="flash"></a>
## 2. ブラウザーからESP32ファームウェアを導入する

1. PCのChrome/Edgeで[書き込みページ](https://igent.cc/flash)を開きます。
2. 基板に印字されたチップに合うプロファイルを選びます。インストーラーはビルド済みの種類を表示します。ESP32-C2は**2 MB以上のフラッシュ**、表の他チップは**4 MB以上**が必要です。PSRAM、画面、外部センサーは不要です。
3. USBの**データ対応ケーブル**で基板をPCに接続します。「USBデバイスを選んでインストール」を押し、シリアルポートの選択画面でその基板を選びます。
4. 導入と検証の完了を待ちます。自動でダウンロードモードに入らない場合は、BOOTを押しながら接続またはリセットし、離して再試行します。
5. 「デバイス情報を読む」で同じ基板を選びます。設定Wi-Fi名、パスワード、電話用リンクが表示されるので、後の手順に備えて保存します。

USBはファームウェア導入、情報の読み出し、給電に使います。電話操作中は電源アダプターなどのUSB電源だけでよく、電話と基板をケーブル接続しません。

インストーラーの **ESP32-C2** は1つの選択肢で、26/40 MHz水晶に合うイメージを自動選択します。2 MB版は単一アプリ領域でOTAはありません。C2は **USB-UART変換**（多くは基板に搭載）で接続し、ネイティブUSB CDCではありません。**ESP32-C5** は80 MHzフラッシュ設定とネイティブUSB CDCを使います。

<a id="wifi"></a>
## 3. ブリッジを普段のWi-Fiにつなぐ

新しい基板で一度行います。

1. **PC**を、インストーラーが示す `iPhone-Harness-…` の設定Wi-Fiへ一時的に接続し、表示されたパスワードを使います。
2. `http://192.168.4.1` を開き、普段のローカルWi-Fiの名前とパスワードを入力します。2.4 GHzネットワークはすべての対応機種で使えます。
3. ページの接続完了を待ち、PCを通常のWi-Fiへ戻します。
4. 電話も同じローカルネットワークに置きます。電話で基板のAPを使ったり、モデル接続を携帯データ通信へ迂回したりする必要はありません。

Wi-Fi情報はブリッジに保存され、次の電源投入で再接続します。設定済みなら省略できます。`http://igent.local/settings` の管理ページでは、ローカル名など公開されているデバイス設定を変更できます。

<a id="bluetooth"></a>
## 4. Bluetooth入力ブリッジをペアリングする

電話の **設定 → Bluetooth** で **iPhone Agent Bridge** をペアリングし、AssistiveTouchを有効のままにします。システムBluetoothはiOSに入力を渡し、ブラウザーとブリッジのネットワーク接続は基板にAgentの命令を渡します。別々の接続です。

HIDレポートが変わるファームウェア更新後は、古いBluetooth登録を削除して再ペアリングします。通常のページ再読み込みやモデル変更では不要です。

<a id="open-harness"></a>
## 5. Web Harnessを開く

電話のSafariで [igent.cc](https://igent.cc/) を開きます。対応iPhone/iPadではHarnessに入り、PCではホーム、スキルコミュニティ、インストーラーを表示します。専用iOSアプリ、証明書プロファイル、Safari拡張、開発者モードは不要です。

操作開始時にSafariが画面共有を求めます。許可し、作業中はロックを解除しておきます。通常のiOS画面共有の確認であり、実験的なローカルネットワーク設定や追加の認証回避は不要です。共有を止めると実行中タスクを一時停止します。「続行」で必要に応じて共有を再要求します。

<a id="models"></a>
## 6. APIまたはChatGPTアカウントを設定する

**設定 → アカウント/API → 追加** を開きます。複数の接続を保存し、会話のモデル選択から切り替えられます。

### APIエンドポイントとキー

1. **OpenAI互換**または **Anthropic互換**APIを選びます。
2. サービスのエンドポイント、APIキー、接続名を入力します。フォームの説明に従ってサービスルートや `/v1` ベースを使います。対応する完全な操作URLもアダプターが正規化します。
3. 「モデルを取得」を押し、一覧から既定モデルを選ぶかIDを入力します。取得した全モデルは会話の選択欄に残ります。
4. 保存します。電話操作には画像理解とツール呼び出しに対応したモデルを選びます。対応するモデルでは推論強度も選択できます。

キーはこのブラウザーに保存します。リクエストは選んだサービスへ直接送信され、サイトのホストを中継しません。サービスが利用中サイトからのブラウザーリクエストを許可している必要があります。

### ChatGPT購読アカウント

最初にChatGPTのセキュリティ設定でデバイスコードログインを有効にします。管理されたワークスペースでは管理者の許可が必要な場合があります。HarnessでChatGPT/Codexを選びログインを開始し、フォームに示された公式確認ページを開いてコードを入力します。公式ページでログインを終えたらHarnessへ戻り、完了ボタンを押します。利用可能モデルを取得して保存します。認証情報はローカルに保持し、アカウントアダプターが更新します。これは通常のOpenAI APIキーとは別の購読接続で、ブラウザーから公式ログインサービスへ到達できる必要があります。[OpenAIのデバイスコード認証手順](https://learn.chatgpt.com/docs/auth#preferred-device-code-authentication-beta)を参照してください。

<a id="bridge"></a>
## 7. ブリッジを接続し、必要なら入力をテストする

1. 会話一覧または会話内のブリッジ状態から「デバイス」を開きます。
2. 未保存なら「ブリッジ情報を取得」でローカルページを開き、戻るリンクを使います。基板のアドレスと公開WebRTC接続情報を読み込みます。インストーラーの電話用リンクも同じ情報を提供します。
3. 「ESP32ブリッジに接続」を押し、必要ならペアリング済みで入力準備完了の電話を選びます。保存後は接続から始められ、ネットワーク設定のやり直しは不要です。
4. 実際のキーボード入力を確認したければ「入力テストを開始」を一度押し、ページとテスト欄を前景に置きます。基板が8桁を入力し、ブラウザーが自動確認します。現行ファームウェアでは任意です。

「更新」は状態を読むだけです。ブリッジ接続、電話のBluetooth接続、入力準備完了は別状態です。初期化中なら少し待って更新します。レート制限で明確に拒否されたテストはカウントダウン後に一度再試行できますが、物理的な結果が不明な入力を無条件で再送しません。接続エラーには状態と理由が表示されます。

「時計を開いて7:00のアラームを設定」など短い依頼を試します。求められた画面共有を許可し、対象アプリへ移動します。Agentは観察・操作・確認を行い、既定ではこのHarness会話へ戻ります。対象アプリに残すには **設定 → タスク完了 → Harnessに戻る** を無効にします。

<a id="clipboard"></a>
## 8. ショートカットでコピーする

1. 電話で[クリップボードの案内](https://igent.cc/shortcuts/clipboard.html)を開き、署名付きショートカットをダウンロードします。
2. Appleのショートカットアプリに **iPhone Agent Clipboard** の正確な名前で追加します。
3. Harnessでブリッジを接続し、Agentがテキストを準備したら「ショートカットでコピー」を押します。ローカルブリッジURLへのアクセスをiOSが尋ねたら許可します。これはショートカット自身の権限です。
4. コピー後にHarnessへ戻ります。コピーの応答を待ち、対象アプリと入力欄を確認してから貼り付けます。

テキストはブラウザーから分割して基板へ送り、1回のローカルHTTPレスポンスでショートカットに渡します。基板に全文を貯める必要はありません。待機中のコピーがなければショートカットはテキストを返さず、クリップボードを変更しません。ショートカットなしでも、前景の「コピーして続行」を使えます。

<a id="install-skills"></a>
## 9. コミュニティスキルを追加する

電話で **設定 → スキル → コミュニティ**、または[公開スキルページ](https://igent.cc/skills)を開きます。手順を読んで「ローカルに追加」を選びます。内蔵スキルも公開パッケージと並び、すでにローカルで利用できます。インストール済み一覧で有効・無効を切り替えます。

再読み込み時に内蔵スキルを更新し、未変更のコミュニティ導入分の更新を確認します。有効状態やローカルの変更は保持します。実行中タスクは開始時の版を使い、更新は後のタスクに適用します。取得したスキルは読み取り専用で元の作者を保持します。

<a id="authoring"></a>
## 10. 自分のスキルを作成・改善する

PCでは[スキルページ](https://igent.cc/skills)の「作成と公開」から「自分のスキルを作成」を選びます。電話では **設定 → スキル → 作成** を使えます。名前、小文字のslug、短い説明、Markdownの操作手順を入力し、ローカル下書きを保存します。

Harnessに作成や改善を頼むこともできます。目的、適用条件、使う操作部品、成功画面、失敗後に変える方法を伝えます。取得スキルと内蔵スキルは読み取り専用です。

所有者はブラウザーが生成した署名IDで、PCとiOSで利用でき、iOS UIDではありません。ブラウザーや装置を変える前にスキルファイルと暗号化した「作者ID」バックアップを保存します。新しいブラウザーでIDを復元し、自作ファイルを読み込むと同じ作者として編集できます。

<a id="publish"></a>
## 11. スキルを共有する

コミュニティページの自作下書きで「公開」を選ぶか、電話の共有パネルから「コミュニティへ公開」を選びます。内容を確認して明示的に公開します。ローカル作者IDで公開パッケージに署名します。編集して再公開すると次の版となり、他ユーザーは導入済みのコピーを更新した際に取得できます。

不具合・要望は [Issues](https://github.com/cccat6/iphone-agent-harness/issues)、コード・文書・翻訳は [PR](https://github.com/cccat6/iphone-agent-harness/pulls) を歓迎します。自作スキルはコードPRではなくサイトのコミュニティで共有してください。

## 会話と自己ホスト

一覧の見出しで会話／アーカイブを切り替えます。通常行はスワイプで名前変更・アーカイブ、アーカイブでは名前変更・復元・削除ができます。過去は上へのスクロールで読み込み、新しい応答が来ても読書位置を保ちます。「最新」で現在の出力へ戻ります。

会話、保存画像、認証情報はこのブラウザーに残ります。メニューで書き出し、設定で読み込みます。会話の書き出しには認証情報を含みません。ホストはページと公開スキルを提供し、選択したモデル/MCPデータは設定先サービスへ直接送ります。[Web Harnessの自己ホスト](../architecture/deployment.md)も可能です。
