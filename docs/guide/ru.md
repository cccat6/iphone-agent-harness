# Настройка и ежедневное использование

[English](README.md) · [简体中文](zh-Hans.md) · [繁體中文](zh-Hant.md) · [日本語](ja.md) · **Русский** · [Deutsch](de.md) · [Français](fr.md) · [Español](es.md) · [Проект](../../README.md) · [Открыть Harness](https://igent.cc/) · [Архитектура](../architecture/overview.md)

Понадобятся iPhone или iPad с iOS/iPadOS 27+, плата ESP32, USB-питание, Wi-Fi и аккаунт ИИ или API-ключ. Прошивка устанавливается через Chrome или Edge на компьютере.

Телефон и мост подключаются к одной сети Wi-Fi. После настройки оставьте мост с питанием в пределах Bluetooth-связи с телефоном.

<a id="accessibility"></a>
## 1. Включите AssistiveTouch

На iPhone откройте **Настройки → Универсальный доступ → Касание → AssistiveTouch** и включите эту функцию. Она позволяет мосту нажимать и перетаскивать элементы с помощью указателя.

<a id="flash"></a>
## 2. Установите прошивку ESP32 из браузера

1. Откройте [веб-установщик](https://igent.cc/flash) в Chrome или Edge на компьютере.
2. Выберите чип, указанный на плате. Для C2 нужно от **2 МБ flash**, для остальных перечисленных чипов — от **4 МБ стандартной SPI flash-памяти**.
3. Подключите плату USB-кабелем для данных. Нажмите **Выбрать USB-устройство и установить**, выберите плату и дождитесь завершения.
4. Нажмите **Прочитать информацию об устройстве**, выберите ту же плату и сохраните показанные данные Wi-Fi и ссылку для телефона.

Если установка не начинается, удерживайте BOOT при повторном подключении USB, отпустите кнопку и повторите попытку. Версия C2 на 26 или 40 МГц выбирается автоматически. После настройки оставьте плату с питанием: телефон управляется по беспроводной связи.

<a id="wifi"></a>
## 3. Подключите мост к обычному Wi-Fi

1. На компьютере подключитесь к сети `iPhone-Harness-…` с паролем из установщика.
2. Откройте `http://192.168.4.1` и введите название и пароль вашей обычной сети Wi-Fi. Сеть 2,4 ГГц подходит для всех поддерживаемых чипов.
3. После подключения моста верните компьютер в обычную сеть. Телефон должен быть в той же сети.

Мост сохраняет сеть и подключается к ней при включении. Настройка нужна только для новой платы или при смене сети. Позже параметры можно изменить на `http://igent.local/settings`.

<a id="bluetooth"></a>
## 4. Выполните Bluetooth-сопряжение

На телефоне откройте **Настройки → Bluetooth** и выполните сопряжение с **iPhone Agent Bridge**. AssistiveTouch должен оставаться включённым.

Bluetooth передаёт нажатия телефону. Подключение Harness к мосту по Wi-Fi выполняется в шаге 7.

<a id="open-harness"></a>
## 5. Откройте Web Harness

Откройте [igent.cc](https://igent.cc/) в Safari на iPhone или iPad — появится Harness.

Когда агенту потребуется управлять телефоном, разрешите трансляцию экрана и оставьте телефон разблокированным. Затем можно перейти в другое приложение. Остановка трансляции приостанавливает задачу. Нажмите **Поделиться экраном и продолжить** в Harness, чтобы снова поделиться экраном и продолжить.

<a id="models"></a>
## 6. Настройте API или аккаунт ChatGPT

Откройте **Настройки → Аккаунты или API → Добавить**. Можно сохранить несколько подключений и выбирать их модели в разговоре.

**API-ключ**

1. Выберите совместимость с **OpenAI** или **Anthropic**, как указано у провайдера.
2. Введите название подключения, адрес API и ключ. Пример адреса: `https://api.example.com/v1`. Подойдёт и полный адрес `/chat/completions` или `/messages` для выбранного типа API.
3. Нажмите **Получить модели**, выберите модель по умолчанию или введите её имя. Остальные модели также останутся доступны.
4. Сохраните. Для управления телефоном нужна модель с поддержкой изображений и вызова инструментов. Уровень рассуждений можно изменить, если модель его поддерживает.

**Аккаунт ChatGPT**

Включите вход по коду устройства в настройках безопасности ChatGPT. Выберите ChatGPT/Codex в Harness, начните вход и введите код на указанной официальной странице. Вернитесь в Harness, завершите вход, загрузите модели и сохраните. В рабочем аккаунте включить эту возможность может администратор. [Инструкция OpenAI](https://learn.chatgpt.com/docs/auth#preferred-device-code-authentication-beta).

Данные входа и ключи сохраняются в этом браузере. Запросы отправляются напрямую провайдеру; его API должен принимать запросы из браузера.

<a id="bridge"></a>
## 7. Подключите мост и при желании проверьте ввод

1. Откройте **Устройства** из списка разговоров или нажмите на состояние моста внутри разговора.
2. При первом подключении нажмите **Получить информацию о мосте**. На странице моста воспользуйтесь ссылкой возврата в Harness. Можно также открыть ссылку для телефона из установщика.
3. Нажмите **Подключить мост ESP32**. Если предложено, выберите сопряжённый телефон. Следующее подключение использует сохранённые данные.
4. Чтобы проверить ввод, нажмите **Начать проверку ввода** и оставайтесь на странице. Мост введёт восемь цифр, а Harness проверит результат. Этот шаг можно пропустить.

Если телефон ещё не готов, проверьте Bluetooth, немного подождите и нажмите **Обновить**.

Попробуйте: «Открой Часы и поставь будильник на 7:00». Разрешите трансляцию экрана. После выполнения агент возвращается в разговор; это можно изменить в **Настройки → Завершение задачи → Вернуться в Harness**.

<a id="clipboard"></a>
## 8. Настройте копирование через «Команды»

1. На телефоне откройте [инструкцию для буфера обмена](https://igent.cc/shortcuts/clipboard.html) и установите команду.
2. Сохраните её имя **iPhone Agent Clipboard**.
3. Подключите мост в Harness. Когда текст готов, выберите **Копировать через Команды**. Разрешите доступ к мосту, если iOS спросит.
4. После копирования вернитесь в Harness для вставки в нужное поле.

Поддерживаются длинные тексты и разные языки. Когда Harness открыт на экране, можно использовать **Копировать и продолжить**.

<a id="install-skills"></a>
## 9. Установите навык сообщества

Откройте **Настройки → Навыки → Сообщество** или [каталог навыков](https://igent.cc/skills). Прочитайте описание и нажмите **Добавить локально**. В своём списке можно включать и выключать навыки.

Встроенные навыки уже установлены. Обновление страницы проверяет новые версии и сохраняет ваши настройки включения. Новые версии используются со следующей задачи.

<a id="authoring"></a>
## 10. Создайте и улучшайте свой навык

На компьютере откройте [Навыки](https://igent.cc/skills) и нажмите **Создать свой навык**. На телефоне: **Настройки → Навыки → Создать**. Введите название, короткий идентификатор строчными латинскими буквами, описание и инструкции, затем сохраните.

Можно попросить Harness написать или улучшить ваш навык. Опишите, когда его применять, что делать и как проверить результат. Чтобы адаптировать чужой навык, создайте свой, оставив оригинал автора.

При смене браузера экспортируйте навыки и сделайте резервную копию **Идентичности автора**. Импортируйте оба файла в новом браузере, чтобы продолжить публикации от того же имени.

<a id="publish"></a>
## 11. Поделитесь навыком

Откройте свой навык и нажмите **Опубликовать** на сайте сообщества или **Опубликовать в сообществе** на телефоне. Проверьте содержимое и подтвердите. Повторная публикация после редактирования обновит навык.

Другие пользователи найдут его в каталоге. Ошибки и идеи отправляйте в [Issues](https://github.com/cccat6/iphone-agent-harness/issues), улучшения кода и документации — через [pull request](https://github.com/cccat6/iphone-agent-harness/pulls).

## Управление разговорами

Нажмите заголовок списка, чтобы переключиться между **Разговорами** и **Архивом**. Смахните разговор для переименования или архивации; в архиве доступны восстановление и удаление. Листайте вверх для чтения истории, а кнопка **Последние** вернёт к свежему ответу.

Экспортируйте разговор из его меню и импортируйте файл в настройках. Файл содержит сообщения и изображения. Данные аккаунтов и ключи хранятся в браузере отдельно.
