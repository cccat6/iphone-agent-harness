# Настройка и ежедневное использование

[English](README.md) · [简体中文](zh-Hans.md) · [繁體中文](zh-Hant.md) · [日本語](ja.md) · **Русский** · [Deutsch](de.md) · [Français](fr.md) · [Español](es.md) · [Проект](../../README.md) · [Открыть Harness](https://igent.cc/) · [Архитектура](../architecture/overview.md)

Нужны iPhone/iPad с iOS/iPadOS 27 или новее, поддерживаемая плата ESP32, USB-питание, локальный Wi-Fi и совместимый аккаунт ИИ или API. Для установки прошивки используйте Chrome или Edge на компьютере. Готовый установщик не требует Arduino, Xcode, аккаунта разработчика или локального компилятора.

Телефон и мост работают в обычной общей сети Wi-Fi. Мост не подключается кабелем к телефону: после настройки его можно оставить с питанием в удобном месте в пределах Bluetooth. Первичную настройку Wi-Fi выполните на компьютере — телефону не понадобится подключаться к настроечной точке доступа платы.

<a id="accessibility"></a>
## 1. Включите AssistiveTouch

Откройте на телефоне **Настройки → Универсальный доступ → Касание → AssistiveTouch** и включите функцию. Через неё мост превращает ввод Bluetooth-указателя в действия в приложениях. Полный доступ с клавиатуры можно оставить в текущем состоянии: он не требуется для команды «Домой» или управления указателем.

<a id="flash"></a>
## 2. Установите прошивку ESP32 из браузера

1. На компьютере откройте [установщик](https://igent.cc/flash) в Chrome или Edge.
2. Выберите профиль чипа, указанного на плате. Установщик показывает уже собранные варианты. ESP32-C2 требуется не менее **2 МБ flash**, остальным чипам в таблице — **4 МБ**. PSRAM, экран и внешние датчики не нужны.
3. Соедините плату с компьютером USB-кабелем **для передачи данных**. Нажмите «Выбрать USB-устройство и установить», затем выберите эту плату в диалоге последовательного порта браузера.
4. Дождитесь установки и проверки. Если режим загрузки не включается автоматически, удерживайте BOOT при подключении или сбросе, отпустите и повторите попытку.
5. Нажмите «Прочитать информацию устройства» и снова выберите ту же плату. Сохраните показанные имя/пароль настроечного Wi-Fi и ссылку для телефона.

USB нужен для прошивки, чтения настройки и питания. Во время управления достаточно адаптера питания или другого USB-источника; кабеля между платой и телефоном нет.

Единый пункт **ESP32-C2** автоматически выбирает образ для кварца 26 или 40 МГц. Образ 2 МБ имеет один раздел приложения без OTA. C2 подключается через **USB–UART** (часто уже на плате), а не встроенный USB CDC. Образ **ESP32-C5** использует flash на 80 МГц и встроенный USB CDC.

<a id="wifi"></a>
## 3. Подключите мост к обычному Wi-Fi

На новой плате сделайте это один раз:

1. На **компьютере** временно подключитесь к сети `iPhone-Harness-…`, показанной установщиком, с указанным там паролем.
2. Откройте `http://192.168.4.1` и введите имя и пароль обычной домашней или рабочей Wi-Fi-сети. Сеть 2,4 ГГц подходит всем поддерживаемым вариантам.
3. Дождитесь подтверждения подключения, затем верните компьютер в обычную сеть.
4. Телефон оставьте в той же локальной сети. Ему не нужны точка доступа платы или переход на мобильные данные ради подключения к модели.

Мост хранит Wi-Fi-параметры локально и подключается при включении. Для уже настроенной платы шаг можно пропустить. Страница `http://igent.local/settings` предоставляет доступные настройки устройства, включая локальное имя.

<a id="bluetooth"></a>
## 4. Выполните Bluetooth-сопряжение

На телефоне откройте **Настройки → Bluetooth** и подключите **iPhone Agent Bridge**. AssistiveTouch должен оставаться включённым. Системный Bluetooth передаёт ввод в iOS, а сеть между браузером и мостом — команды агента плате. Это независимые соединения.

Если обновление прошивки меняет HID-отчёты, удалите старую запись в настройках Bluetooth и выполните сопряжение заново. Обычное обновление страницы или смена модели этого не требует.

<a id="open-harness"></a>
## 5. Откройте Web Harness

Откройте [igent.cc](https://igent.cc/) в Safari на телефоне. Совместимые iPhone/iPad переходят в Harness, компьютеры — на главную страницу с сообществом навыков и установщиком. Отдельное iOS-приложение, профиль сертификата, расширение Safari и режим разработчика не нужны.

При начале действия Safari запросит трансляцию экрана. Разрешите её и оставьте телефон разблокированным. Это стандартный запрос iOS; включать экспериментальные сетевые флаги или обходить дополнительную авторизацию не требуется. Остановка трансляции приостанавливает задачу. «Продолжить» при необходимости снова запросит доступ к экрану.

<a id="models"></a>
## 6. Настройте API или аккаунт ChatGPT

Откройте **Настройки → Аккаунты или API → Добавить**. Можно сохранить несколько подключений и выбирать их модели в разговоре.

### Endpoint и ключ API

1. Выберите API, **совместимый с OpenAI** или **Anthropic**.
2. Введите адрес провайдера, ключ API и имя подключения. Следуйте подсказке формы: подходит корень сервиса или база `/v1`; поддерживаемый полный URL операции адаптер также нормализует.
3. Нажмите «Получить модели». Выберите модель по умолчанию либо впишите её ID. Все полученные модели останутся в селекторе разговора.
4. Сохраните. Для управления нужен анализ изображений и вызов инструментов. Если модель поддерживает уровень рассуждения, задайте его в селекторе.

Ключи сохраняются в этом браузере. Запрос идёт напрямую провайдеру, не через хост сайта. Провайдер должен разрешать браузерные запросы с используемого вами сайта.

### Аккаунт с подпиской ChatGPT

Сначала включите вход по коду устройства в настройках безопасности ChatGPT; для управляемого рабочего пространства может понадобиться разрешение администратора. В Harness выберите ChatGPT/Codex и начните вход. Откройте официальную страницу проверки из формы, введите показанный код и завершите авторизацию. Вернитесь в Harness, нажмите кнопку завершения, загрузите модели и сохраните подключение. Учётные данные остаются локально, а адаптер аккаунта обновляет их. Это подключение по подписке, а не обычный ключ OpenAI API; официальный сервис входа должен быть доступен браузеру. См. [инструкцию OpenAI по коду устройства](https://learn.chatgpt.com/docs/auth#preferred-device-code-authentication-beta).

<a id="bridge"></a>
## 7. Подключите мост и при желании проверьте ввод

1. Откройте «Устройства» из списка разговоров или статуса моста в разговоре.
2. Если сведения ещё не сохранены, выберите «Получить информацию моста», откройте его локальную страницу и воспользуйтесь ссылкой возврата. Она импортирует адрес платы и публичные данные WebRTC. Ссылка для телефона из установщика передаёт те же сведения.
3. Нажмите «Подключить мост ESP32» и при необходимости выберите сопряжённый телефон, готовый к вводу. При следующем использовании достаточно подключения без повторной настройки Wi-Fi.
4. Для дополнительной проверки нативной клавиатуры один раз нажмите «Начать тест ввода» и держите страницу с тестовым полем на переднем плане. Плата введёт восемь цифр, браузер подтвердит результат автоматически. В текущей прошивке тест необязателен.

«Обновить» только читает состояние. Подключение моста, Bluetooth телефона и готовность ввода — разные статусы. Если ввод инициализируется, немного подождите и обновите. Явно отклонённый из-за ограничения частоты тест показывает обратный отсчёт и может повториться один раз; ввод с неизвестным физическим результатом вслепую не пересылается. Ошибка подключения показывает статус и причину.

Попробуйте «Открой Часы и поставь будильник на 7:00». Разрешите трансляцию и перейдите в нужное приложение. Агент наблюдает, действует и проверяет, затем по умолчанию возвращается в этот разговор. Чтобы оставить целевое приложение открытым, отключите **Настройки → Завершение задачи → Возврат в Harness**.

<a id="clipboard"></a>
## 8. Настройте копирование через «Команды»

1. На телефоне откройте [инструкцию буфера обмена](https://igent.cc/shortcuts/clipboard.html) и скачайте подписанную команду.
2. Добавьте её в приложение Apple «Команды» под точным именем **iPhone Agent Clipboard**.
3. Подключите мост в Harness. Когда агент подготовит текст, нажмите «Копировать через Команды». Если iOS запросит доступ команды к локальному URL моста, разрешите: это собственное разрешение команды.
4. После копирования вернитесь в Harness. Он дождётся подтверждения копии и проверит приложение и поле назначения перед вставкой.

Браузер передаёт текст плате частями, а она выдаёт его команде одним локальным HTTP-ответом. Весь текст не нужно хранить в буфере платы. При отсутствии ожидающей задачи команда не возвращает текст и не меняет буфер обмена. Кнопка «Копировать и продолжить» доступна на переднем плане и без команды.

<a id="install-skills"></a>
## 9. Установите навык сообщества

На телефоне откройте **Настройки → Навыки → Сообщество** или [каталог](https://igent.cc/skills). Прочитайте инструкцию и выберите «Добавить локально». Встроенные навыки показаны рядом с публикациями сообщества и уже доступны локально. В списке установленного можно включать и выключать навыки.

Перезагрузка страницы обновляет встроенные навыки и проверяет новые версии неизменённых установок сообщества. Состояние включения и локальные изменения сохраняются. Активная задача продолжает со своими начальными версиями, обновления применяются к следующим задачам. Загруженные навыки остаются только для чтения и сохраняют автора.

<a id="authoring"></a>
## 10. Создайте и улучшайте свой навык

На компьютере откройте [Навыки](https://igent.cc/skills) и выберите «Создать свой навык» в блоке создания и публикации. На телефоне доступно **Настройки → Навыки → Создать**. Задайте имя, slug строчными буквами, краткое описание и инструкции Markdown, затем сохраните локальный черновик.

Можно попросить Harness создать или улучшить ваш навык. Опишите цель, условия применения, нужные элементы управления, признаки успеха на снимке и изменения после неудачи. Встроенные и чужие загруженные навыки остаются только для чтения.

Владение определяется подписью браузерной идентичности, доступной и на компьютере, и в iOS, а не UID iOS. Перед сменой браузера или устройства экспортируйте файл навыка и зашифрованную копию «Идентичности автора». В новом браузере восстановите её и импортируйте свой файл для продолжения редактирования под тем же автором.

<a id="publish"></a>
## 11. Поделитесь навыком

В сообществе выберите «Опубликовать» для своего черновика, либо откройте панель обмена навыком на телефоне и выберите публикацию в сообществе. Проверьте содержимое и подтвердите. Публичный пакет подписывается локальной идентичностью автора. Изменение и новая публикация создают следующую версию; другие пользователи получают её при обновлении установленных копий.

Для ошибок и пожеланий используйте [Issues](https://github.com/cccat6/iphone-agent-harness/issues), для кода, документации и переводов — [PR](https://github.com/cccat6/iphone-agent-harness/pulls). Собственными навыками делитесь через сайт сообщества вместо PR с кодом.

## Разговоры и свой сервер

Заголовок списка переключает разговоры и архив. Смахивание даёт переименование/архивирование, а в архиве — переименование/восстановление/удаление. Старые сообщения загружаются при прокрутке вверх; новые ответы сохраняют место чтения. «Последние» возвращает к текущему выводу.

Разговоры, сохранённые изображения и учётные данные остаются в этом браузере. Экспортируйте через меню и импортируйте в настройках; учётные данные не входят в экспорт. Хост предоставляет страницы и публичные навыки, а выбранные данные моделей/MCP идут напрямую соответствующим сервисам. Можно [разместить Web Harness самостоятельно](../architecture/deployment.md).
