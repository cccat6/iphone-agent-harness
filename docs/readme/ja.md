## 5ステップで開始

iOS/iPadOS 27以降のSafari、4 MB以上のESP32/C3/S3/C6、データ対応USBケーブル、同じ2.4 GHz Wi-Fi、AIアカウントまたは互換APIが必要です。ブラウザー書き込みはPCのChrome/Edgeを使います。

1. **ファームウェアを導入.** PCの書き込みページでボードを選び導入し、装置情報と電話用リンクを取得します。新品のボードは設定Wi-Fiにつなぎ通常のネットワークを保存し、電話を同じネットワークに戻します。

2. **電話を接続.** 提供リンクまたはHarnessのブリッジ情報取得を使い、保存後にESP32ブリッジへ接続します。iOS BluetoothでiPhone Agent Bridgeをペアリングし、AssistiveTouchを有効にして準備済みの電話を選びます。現行版の8桁入力テストは任意です。フルキーボードアクセスの状態は問いません。接続コード、証明書導入、追加タブは不要です。

3. **AIを選択.** 設定のアカウント/APIでエンドポイントとキーを登録してモデルを取得するか、ChatGPTログインを進めます。既定モデルは選択・手入力でき、取得した全モデルを切り替えられます。会話を作りモデルと対応する推論強度を選びます。

4. **画面を共有して依頼.** 画面共有を開始し、テスト用アラームなど短い依頼から試します。能力の質問には説明、計画の依頼には確認可能な計画、明確な操作依頼には実行で応えます。ロックを解除して最初の動作を見守ってください。停止は終了、共有喪失は一時停止です。

5. **結果を確認.** AIは結果を確認してから終了し、既定ではHarnessへ戻ります。設定のタスク完了で戻る動作を無効にできます。重要な操作は実際の画面も確認してください。

## 日常の操作

- 会話一覧の見出しで通常／アーカイブを切り替えます。通常行をスワイプすると名前変更／アーカイブ、アーカイブでは名前変更／復元／削除。削除は確認が必要です。一覧を下に引くか検索ボタンで探します。

- 上へスクロールすると過去を読み込み、新着が来ても読書位置を保ちます。「最新」で戻ります。会話メニューで書き出し、設定で読み込みます。画像込み64 MiBまでです。

- 長文はクリップボードの案内からiPhone Agent Clipboardを追加します。ショートカットでコピー、または前景のコピーして続行を使います。コピー確認と対象欄の確認後に貼り付けます。

- 12の内蔵スキルが観察、計画、操作、復旧、作成、時計、ジェスチャー修正を案内します。対応する部品では数字を直接編集し、それ以外は小さく調整し静止を待ちます。

- PCでも電話でも自分のスキルを作成・編集・公開できます。所有者はブラウザー生成の暗号IDで、iOS端末UIDではありません。ブラウザー変更前に暗号化バックアップを保存してください。内蔵・取得スキルは読み取り専用で、更新時も有効状態を保持し、取得失敗時は旧版を残します。

- 任意のMCPはブラウザーから利用できるStreamable HTTPサーバーに対応します。ツールを明示許可し、サーバーのCORS対応が必要です。stdioや完全なリモートOAuthホストは提供しません。

## データと制限

会話、画像、APIキー、ログイントークンはこのブラウザーに保存します。資格情報は会話の書き出しに含まず、解除パスワードは不要です。選択した内容はモデルサービスへ送ります。サイトデータ削除で失われるため、重要な会話を保存してください。公開は明示選択したスキルだけを送信します。

実験的なハードウェア機能は見守りながら使ってください。ジェスチャー、背景キャプチャー、ショートカット、複数電話は各実機で確認が必要で、ビルドやPC検証は代替しません。Safariは背景処理を止める場合があります。タスク全体の既定時間・回数制限はありませんが各計画に安全制限があります。SafariのChatGPT購読ログイン・更新には互換性の境界があります。ブリッジの活動中WebRTC接続は1つです。複数クライアント登録・読み込みの最新修正はソースで準備済みで、実機への書き込みと確認は未実施です。

## 開発と自己ホスト

Node.js 22.13以降を使用します。apps/webとfirmware/IPhoneAutomationHarnessの2部分で、静的サイトに任意の署名付き公開スキルAPIを組み合わせます。電話の画面共有にはHTTPSが必要です。

```sh
npm ci
npm test
npm run build
npm run preview
```

リリースは手動です。通常のpushはGitHub Actionsを開始しません。再利用・配布・配備はガイドを参照してください。
