## Пять шагов

Нужны Safari на iOS/iPadOS 27+, ESP32/C3/S3/C6 с флеш-памятью от 4 МБ, USB-кабель для данных, общая сеть Wi-Fi 2,4 ГГц и аккаунт ИИ или совместимый API. Для прошивки в браузере используйте Chrome/Edge на компьютере.

1. **Установите прошивку.** Откройте установщик на компьютере, выберите плату и прошейте её. Прочитайте сведения и сохраните ссылку для телефона. Новую плату подключите к обычной сети через её настроечный Wi-Fi, затем верните телефон в ту же сеть.

2. **Подключите телефон.** Откройте ссылку или получите сведения о мосте в Harness, сохраните их и подключите ESP32. В Bluetooth iOS выполните сопряжение с iPhone Agent Bridge, включите AssistiveTouch и выберите готовый телефон. Тест восьми цифр в новой прошивке необязателен; полный доступ с клавиатуры может быть включён или выключен. Код, сертификат и отдельная вкладка не нужны.

3. **Выберите ИИ.** В настройках аккаунтов/API добавьте адрес и ключ, загрузите модели либо войдите в ChatGPT. Модель по умолчанию можно выбрать или вписать; все полученные модели доступны для переключения. Создайте разговор и выберите модель и доступный уровень рассуждения.

4. **Поделитесь экраном и задайте задачу.** Начните с короткой безопасной задачи, например тестового будильника. Вопрос о возможностях получает ответ, просьба о плане — проверяемый план, явная команда — выполнение. Не блокируйте телефон и наблюдайте первые действия. Стоп завершает работу, потеря трансляции приостанавливает её.

5. **Проверьте результат.** Перед завершением ИИ проверяет результат и по умолчанию возвращается в Harness. Это можно отключить в настройках завершения задачи. Важные результаты проверяйте на экране самостоятельно.

## Ежедневное использование

- Переключайте разговоры и архив селектором заголовка списка. Смахивание открывает переименование/архивирование, в архиве — переименование/восстановление/удаление с подтверждением. Для поиска потяните список вниз или нажмите поиск.

- Старые сообщения загружаются при прокрутке вверх. Новые ответы сохраняют позицию чтения; «Последние» возвращает к новым. Экспорт — в меню разговора, импорт — в настройках. Лимит файла с изображениями 64 МиБ.

- Для длинного текста установите iPhone Agent Clipboard по инструкции. Копируйте через Shortcuts или кнопку в открытом браузере. Задача ждёт подтверждения копирования и проверки поля перед вставкой.

- 12 встроенных навыков охватывают наблюдение, планирование, ввод, восстановление, создание, часы и коррекцию жестов. Используется прямой ввод чисел, если элемент его поддерживает; иначе — небольшие поправки и ожидание остановки.

- Создавайте, редактируйте и публикуйте свои навыки на компьютере или телефоне. Владение определяется криптографической идентичностью браузера, а не UID iOS. Перед сменой браузера сделайте зашифрованную резервную копию. Встроенные и загруженные навыки доступны только для чтения; обновления сохраняют включение, а ошибка оставляет текущую версию.

- Необязательный MCP работает с доступными браузеру Streamable HTTP-серверами. Явно выберите инструменты; серверу нужен CORS. Запуск stdio и полный хостинг удалённого OAuth не поддерживаются.

## Данные и ограничения

Разговоры, изображения, ключи и токены сохраняются в этом браузере. Учётные данные не входят в экспорт и не требуют пароля разблокировки. Выбранные сообщения и изображения отправляются модели. Очистка данных сайта удаляет их; экспортируйте важные разговоры. Публикация отправляет только явно выбранный пакет навыка.

Экспериментальные аппаратные функции используйте под наблюдением. Жесты, фоновые снимки, Shortcuts и несколько телефонов требуют проверки на ваших устройствах; сборка и компьютерные тесты этого не доказывают. Safari может приостанавливать фон. Общего лимита задачи по умолчанию нет, но отдельные планы имеют ограничения безопасности. Вход и обновление подписки ChatGPT в Safari остаются границей совместимости. Мост допускает одно активное соединение WebRTC. Исправление регистрации/импорта нескольких клиентов подготовлено в исходниках, но ещё не прошито и не проверено на плате.

## Разработка и свой сервер

Используйте Node.js 22.13+. Две части продукта: apps/web и firmware/IPhoneAutomationHarness. Сайт статический, API публикации подписанных навыков необязателен. Трансляции экрана нужен HTTPS.

```sh
npm ci
npm test
npm run build
npm run preview
```

Выпуски запускаются вручную; обычный push не запускает GitHub Actions. Повторное использование прошивок и развёртывание описаны в руководстве.
