# iPhone Agent Harness

[English](../../README.md) · [简体中文](zh-Hans.md) · [繁體中文](zh-Hant.md) · [日本語](ja.md) · **Русский** · [Deutsch](de.md) · [Français](fr.md) · [Español](es.md)

Открытая среда для ИИ-агента, который управляет iPhone и iPad в разных приложениях через браузер и Bluetooth-контроллер ESP32.

Платформа — **Safari на iOS/iPadOS 27 и новее**. На iPhone и iPad открывается Harness, а на компьютере — описание проекта, сообщество навыков и установка прошивки ESP32.

Руководство: [English](../acceptance/README.md) · [简体中文](../acceptance/zh-Hans.md). Основные экраны и повседневные действия.

Сайт проекта — [igent.cc](https://igent.cc). После подключения вернитесь в Harness и оставьте вкладку подключения устройства открытой. Устанавливать сертификат не нужно; команды не передаются через облако. На iPhone с Safari 27.0.1 успешно выполнены пять GET/POST-запросов примерно за 21 секунду, в том числе при обеих фоновых вкладках во время захвата экрана. Это не подтверждает неограниченную фоновую работу или полную проверку управления телефоном. См. [результаты проверки](../architecture/lan-connection.md).

## Возможности

- **Чаты:** локальные сообщения и изображения, поиск, переименование, закрепление, архив, импорт и экспорт файлов. Режимы общения, планирования и выполнения задач.
- **Аккаунты и API:** несколько подключений, API в формате OpenAI и Anthropic, получение списка моделей и переключение между ними. Интерфейс входа и адаптер подписки ChatGPT реализованы; реальный вход из Safari ещё проверяется.
- **Контекст:** модель автоматически пересказывает предыдущие сообщения при достижении настраиваемого порога — по умолчанию **750 000 токенов**. Полная история остаётся на устройстве.
- **Изображения:** сжатие в JPEG с исходными размерами и тремя уровнями качества.
- **Навыки:** десять встроенных навыков, создание и редактирование собственных, загрузка из сообщества и публикация. Адрес официального сообщества уже настроен. Harness помогает писать и улучшать свои навыки в чате.
- **MCP:** несколько серверов Streamable HTTP, независимый выбор инструментов и их использование в режиме задачи.

Чаты сохраняются в браузере; выбранные сообщения и изображения отправляются выбранному ИИ-сервису. Ключи API и данные входа по умолчанию остаются в памяти страницы; доступно зашифрованное сохранение на устройстве.

## Структура и локальный запуск

Две части продукта: `apps/web/` (сайт, Harness и сообщество навыков) и `firmware/IPhoneAutomationHarness/` (прошивка Arduino). Сайт можно разместить самостоятельно.

Используйте Node.js 22.13 или новее:

```sh
npm ci
npm test
npm run build
npm run preview
```

На компьютере доступен предпросмотр через localhost, а для показа экрана телефона нужен HTTPS. Разместите `build/site` согласно [настройкам маршрутов](../architecture/deployment.md#self-hosted-page-routing). Платы и сборка описаны в [руководстве Arduino](../../firmware/IPhoneAutomationHarness/README.md).

**Ручные релизы:** обычный push не запускает GitHub Actions. По запросу неизменённая прошивка используется повторно, а изменённая собирается для ESP32/C3/S3/C6. Одинаковые бинарные файлы публикуются в Releases и на сайте. [Настройка выпуска](../architecture/manual-release.md).
