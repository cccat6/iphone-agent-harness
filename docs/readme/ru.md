# iPhone Agent Harness

[English](../../README.md) · [简体中文](zh-Hans.md) · [繁體中文](zh-Hant.md) · [日本語](ja.md) · **Русский** · [Deutsch](de.md) · [Français](fr.md) · [Español](es.md)

Открытая среда для ИИ-агента, который управляет iPhone и iPad в разных приложениях через браузер и Bluetooth HID-мост на ESP32.

Целевая платформа — **Safari на iOS/iPadOS 27 и новее**. На телефоне и планшете по умолчанию открывается Harness; на компьютере — главная страница, сообщество Skills и страницы настройки ESP32 и прошивки. Нативное приложение и версия для Android не планируются.

## Состояние проекта

Веб-приложение, защищённый транспорт команд в локальной сети и интерфейс настройки устройства реализованы. Сайт и сообщество Skill с проверкой подписей развёрнуты на [igent.cc](https://igent.cc). Проверка продуктовой прошивки на реальном устройстве продолжается: сборка, тесты на компьютере и имитация в браузере не подтверждают работу ввода на телефоне или подключение Safari к локальной сети.

В отдельных экспериментах на iPhone 12 с iOS 27.0.1 подтверждены захват других приложений, фоновые запросы с задержкой и потоковые ответы, а также четыре коротких реальных запроса DeepSeek через оба совместимых протокола. Старая экспериментальная прошивка также выполняла ввод с клавиатуры, Home, перемещение указателя и свайп. Это не проверка новой прошивки и не обещание неограниченной фоновой работы. См. [результаты](../research/background-api.md) и [границы реализации](../architecture/firmware-implementation.md).

## Возможности

- **Локальные диалоги:** IndexedDB, вложения, импорт и экспорт, режимы общения, планирования и выполнения, отмена. Выбранные сообщения и изображения отправляются настроенному вами ИИ-сервису; собственной облачной базы диалогов у проекта нет.
- **Модели и аккаунты:** совместимые API OpenAI/Anthropic, получение списка моделей и несколько профилей. Реализованы код устройства, обновление токенов и Responses для подписки Codex. Реальный вход в Safari и CORS старых адресов Codex ещё не проверены; ошибка не отображается как успешное подключение.
- **Контекст и изображения:** пороги и целевой объём сжатия, резерв ответа, число изображений, модельное резюме или выдержки. Число токенов оценивается приблизительно. Можно настроить размер и качество JPEG; сохраняются масштаб и время. Статистика кеша зависит от ответа сервиса, попадание в кеш не гарантируется.
- **10 встроенных Skills:** наблюдение экрана и его изменений, планирование, навигация, ввод текста, прокрутка, перетаскивание, восстановление, выбор способа работы с проверкой и создание Skills. Набор инструментов фиксирован, исполняемые плагины не устанавливаются.
- **Авторство и сообщество:** локальная идентичность P-256, зашифрованная резервная копия и перенос на другое устройство. Редактируются только собственные Skills; загруженные из сообщества доступны только для чтения. Публикация требует явного действия пользователя. Дополнительный API сообщества **развёрнут на официальном сайте** и хранит только явно опубликованные пакеты.

По умолчанию учётные данные находятся в памяти. Их можно зашифровать для локального хранения и разблокировать парольной фразой; в статическую сборку они не входят. Подробности — в [описании подписки](../research/codex-subscription.md).

## Запуск

Две части продукта: `apps/web/` и `firmware/IPhoneAutomationHarness/`. Сообщество и дополнительный API относятся к Web. Статический сайт можно разместить самостоятельно, сервер сообщества для локальной работы не нужен.

Требуется Node.js 22.13 или новее:

```sh
npm ci
npm test
npm run build
npm run preview
```

На компьютере доступен предпросмотр через localhost. Для захвата экрана телефона нужен **HTTPS**. Разместите `build/site` на Cloudflare или HTTPS-сервере с указанной [маршрутизацией страниц](../architecture/deployment.md#self-hosted-page-routing). Инструменты сборки прошивки описаны в [руководстве Arduino](../../firmware/IPhoneAutomationHarness/README.md).

[Архитектура](../architecture/system-blueprint.md) · [Жесты и синхронизация кадров](../architecture/actions.md) · [Авторство Skills](../architecture/skill-community.md) · [Локализация](../architecture/localization.md)

Остаётся проверить безопасную первичную настройку Wi-Fi, привязку телефона, связь Safari с ESP32 в локальной сети, инерционные жесты и изоляцию двух телефонов на одном C3. mDNS помогает находить адрес, но не заменяет HTTPS и авторизацию.

Полный список приёмки: [English](../acceptance/README.md) · [简体中文](../acceptance/zh-Hans.md). Он охватывает все функции и материалы, результаты проверок на компьютере и отложенные шаги на телефоне. Подготовку на компьютере и финальную проверку выпуска выполняет команда проекта.

На Mac успешно проверены HTTPS с проверкой CA/DNS и сопряжение владельца через рабочий клиент с реальной C3. Команды телефону не отправлялись. Финальный образ и Safari/телефон требуют отдельной приёмки. [Протокол проверки клиента](../research/device-client-live-verification.json).
