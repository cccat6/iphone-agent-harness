# 手机与桥的连接

[English technical guide](secure-lan.md) · [手机教程](../guide/zh-Hans.md#bridge)

1. 在电脑烧录页安装固件，读取设备信息，取得手机链接。
2. 首次使用时，连接设备的设置 Wi-Fi，保存常用的 2.4 GHz 网络。手机与桥随后使用同一局域网。
3. 打开手机链接，或在 Harness 点“获取桥的信息”，进入设备设置页，再点“返回设备连接”。连接信息会保存在浏览器中。
4. 在系统蓝牙中配对 **iPhone Agent Bridge**，开启辅助触控。在 Harness 点“连接 ESP32 桥”，选择已连接的手机。需要检查键盘输入时，可以运行数字输入测试。

日常控制通过当前 Harness 页面的 WebRTC Direct 连接传输。设备的本地 HTTP 页面负责配网、设置和快捷指令。默认管理地址为 `http://igent.local`；网络或设备地址变化后，重新获取桥的信息即可更新。

连接面板分别显示桥连接、蓝牙手机和屏幕共享状态。断开会停止发送输入，重新连接后更新当前目标。站内前进与返回保留连接和共享；刷新页面后需要重新开始屏幕共享。

每块桥支持两条独立的 WebRTC 控制连接，每台手机同时由一个任务操作。多台手机使用时，建议在各自网页分别运行连接测试，确认选中了对应手机。连接失败时，检查手机与桥所在的网络、路由器客户端隔离设置和蓝牙连接状态。
