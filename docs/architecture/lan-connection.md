# 手机与桥的连接

[English technical guide](secure-lan.md) · [手机教程](../acceptance/zh-Hans.md)

1. 新板子先在电脑烧录页安装固件，读取设备信息，取得手机链接。
2. 如需配网，连接设备提供的设置 Wi-Fi，打开随附地址，保存常用的 2.4 GHz Wi-Fi。手机随后回到同一网络。
3. 打开电脑给出的链接，或在 Harness 点“获取桥的信息”，进入设备设置页后点“返回设备连接”。返回链接带回实际连接地址，不需手填 IP。
4. 信息保存后点“连接 ESP32 桥”。在系统蓝牙配对 **iPhone Agent Bridge**、开启辅助触控，并在 Harness 选择可用手机。新固件绑定后即可就绪，数字输入测试为可选检查；旧固件保留旧版测试／更新提示。

日常控制通过同一 Harness 页面的 WebRTC Direct 完成，无云端指令中继、额外连接标签页、连接码或手机证书安装。设备本地 HTTP 页用于配网、改名及快捷指令。默认管理名为 `igent.local`；改名或地址变化后从设备设置页重新导入信息。

断开后应显示真实离线状态并停止下发输入；重新连接后核对当前可用目标。站内返回／前进保留同一文档中的连接与共享；刷新或离开文档需要重新授权取屏。

连接失败时检查同一网络、Wi-Fi客户端隔离、手机本地网络权限和蓝牙状态；不要以页面已打开推定手机可控。桥目前只有一个活动 WebRTC 连接。最新多客户端注册／导入修复已准备在源码，尚未刷入设备验证；多手机操作仍需实机确认。
