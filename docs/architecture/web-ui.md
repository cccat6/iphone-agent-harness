# Web interface

Phone/tablet entry opens Harness. Desktop entry opens the homepage with Skills and firmware installation. The site has eight languages and uses system fonts. User titles, messages, provider/model IDs and skill bodies retain their original content.

The session-list title selector switches between conversations and archives. Normal rows reveal Rename/Archive on swipe; archived rows reveal Rename/Restore/Delete. Deletion requires confirmation. Search can be opened by pulling down at the list top or using the search button. A separate row menu supports non-swipe access.

Conversation history loads in indexed windows; image data loads when visible. Scrolling up preserves an anchor while old messages load. New text preserves the reader’s current position. Latest reloads the recent window and enables following. Unsent drafts are stored per session for the current page lifetime.

Settings group Accounts or API, Devices, Skills, MCP, Context and images, Language, local data and Task completion. Archives are selected from the session-list title. Task completion defaults to return to Harness after checking the result and can be disabled.

One composer serves discussion, reviewable planning and execution according to intent. Internal Back/Forward transitions keep the same document and connection/capture owner; full reload or real document exit needs fresh screen-sharing authorization. Mobile panels retain reachable back/close controls while content scrolls.
