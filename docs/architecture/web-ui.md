# Web 界面实施说明

产品名为 iPhone Automation Harness。`apps/web/` 是无框架、无远程字体和无打包前提的静态 ES module 页面，可部署在子路径。对话、设备、模型和 Skill 共用一个入口。

## 导航与布局

- 手机首先显示会话列表，提供搜索、新建、归档入口，以及底部设备 / Skills / 设置。打开会话后进入独立对话页，顶部返回按钮保留列表位置。
- 宽屏显示左侧列表和右侧对话。对话顶部只有标题、模式说明与更多菜单；底部有输入、chat / plan / task、模型、Skills、发送 / 停止。
- 会话菜单提供重命名、置顶、复制 ID、导出、归档与删除。删除需用户明确确认，不提供文件目录或仓库等不相关操作。
- 对话默认渲染最近 80 条，用户按需加载较早消息。当前 store 接口仍返回全部消息，数据库级分页属于后续性能改进。
- 样式使用系统字体、safe-area、动态视口和 `visualViewport` 高度；输入字号避免 iPhone 聚焦自动缩放。模态窗口在手机上呈底部面板，在桌面居中。

## 真实状态与持久化

- 模型配置只包含 provider ID、显示名称、协议、基础地址、模型与 stream。密钥默认仅经 `setCredential()` 保存到页面内存，不进入会话、分享或导出；用户可明确选择 AES-GCM 加密保存到 IndexedDB，口令不保存，刷新后主动解锁到页面内存。连接移除时同步移除其本地密文。
- 设备地址保存不代表连接或控制授权。身份检查使用 `DeviceClient.identity()`，成功也只显示“收到身份响应，控制绑定尚未完成”。不自动调用 HID。
- 屏幕共享使用 core 导出的 `screenCapture` 共享实例。启动由用户点击；单帧检查仅获取图像尺寸，不上传画面。是否启用控制由核心判定。
- ChatGPT 账户登录显示未接入，无伪设备码页面。MCP 设置支持配置 Streamable HTTP 地址、内存令牌、初始化和真实工具目录读取；不执行工具、不自动加入任务，静态前端不会运行本地 stdio MCP 进程。
- 模型设置提供“获取模型”按钮与实际接口返回的下拉选择，失败时保留手动模型 ID。发现模型不发起生成请求，支持 OpenAI / Anthropic 风格，兼容映射交给 core。
- 存储页显示浏览器估算用量和持久化状态；持久化申请返回未获准时直接报告，提供会话 JSON 导入 / 导出。

## Skill 流程

公开目录为数组或 `{ "skills": [...] }`，条目包含 `id`、`name`、`description`、`version`、可选 `url`。目录和正文需允许浏览器跨域读取。JSON Skill 使用 `content`，兼容 `instructions` / `body`；Markdown 文件按文本导入。外来文本以文字呈现，不执行 HTML 或脚本。

用户逐项添加到本地，可启用 / 停用 / 查看 / 删除，已有条目更新前需确认。发布设置为空时只能导出 Skill 文件；只有用户明确配置 `skillPublishUrl`，界面才出现上传按钮，每次公开发布前再次确认。上传 payload 仅包含 Skill 字段，不包含会话和模型凭据。第三方发布服务的鉴权、审核和目录维护不由静态页面伪装完成。

## 验收边界

本轮通过 CUA 浏览器在默认桌面视口和 390×844 手机断点进行交互验收：

- 会话新建、重命名、置顶、搜索空结果、归档与恢复；刷新后记录仍存在。
- 使用非真实测试 Key 和 `example.invalid` 保存 provider；加密保存后刷新显示待解锁，输入测试口令后恢复到内存。
- 模型发现真实请求不可达端点后报告失败，保留手填字段，不生成候选。
- 从本地导入无敏感信息的测试 Skill，显示本地记录；无发布端点时只显示导出；不存在的源目录报告 HTTP 404。

没有输入真实 API Key、调用真实模型生成、连接 MCP 或发送 HID。手机断点预览不能替代真实 Safari：手机软键盘、原生共享界面、后台保持、多目标 BLE 和真实模型 API 仍需真机验收。
