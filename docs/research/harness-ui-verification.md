## 第二阶段：多账号、上下文与图片

使用仅本机 `127.0.0.1:18830` 的模拟目录服务器返回两个明确标注的测试模型；它没有生成接口，不使用凭据。OpenAI 风格 GET /models 和 Anthropic 风格 GET /v1/models（含正常 OPTIONS/CORS）均成功返回真实目录。保存两个账号后，选择器出现两个账号分组、四个模型选项；切换到账号 B 的 Beta，再切换会话，所选值仍为该 profileId::modelId。

上下文配置保存为 autoCompact=true、triggerTokens=32000、targetTokens=10000、reserveTokens=5000、maxImages=6、strategy=extractive；图片设置 maxSide=960、quality=0.68。刷新后通过真实表单逐项确认这些值保留。模型/图片的核心压缩算法由主 agent 独立测试；本段只证明 UI 配置、持久化和字段传递。

Codex 订阅账号能单独创建并显示“尚未登录”；保存前设备码按钮禁用，保存后显示主动登录入口；没有在本轮发出真实授权、目录或生成请求，因此不宣称第三方浏览器 OAuth/CORS 已打通。凭据只交账户模块或加密 vault，不写入普通设置。

## 最终多语言与平台入口

正式名称更新为 **iPhone Agent Harness**，存储命名空间和协议 ID 保持兼容。UI 使用 324 个相同键集合的八语言资源：英语、简中、繁中、日语、俄语、德语、法语、西班牙语。支持系统语言优先列表、显式中文脚本优先、手动选择与本地偏好保存。核心错误按稳定 code / message 目录本地化，未知服务细节保留。

实际浏览器已确认：

- 桌面入口是主页 / Skill 社区 / 固件安装，没有显示手机 Harness。
- 英语主页与社区可正常显示，目录有 10 个内置 Skill（包括 skill-authoring）。英语阶段图为 `final-home-en.jpg`、`final-community-en.jpg`；它们拍摄于更名前，不能当作最终 Agent 品牌上线图。
- 英语→简中热切换成功。繁中、日语、俄语、德语、法语、西班牙语的语言弹窗标题、说明、当前选中项均由原生 Chrome AX 确认；德语单独复核了实际生效状态。
- 通过“创建自己的 Skill”表单创建测试条目，姓名、简介和正文均为“设置”；英语 UI 中标题、简介及正文保留“设置”，没有变为 Settings。自有条目显示可编辑，内置与导入来源只读。详情页标题 / 副标题 / 正文也实际确认原样。
- 从目录获取的内容使用独立来源命名空间，与 builtin / authored 并存；用户停用状态跨初始化保持。

多语言 DOM 适配会在遍历时暂停自身 MutationObserver，结束后恢复，并用有界的下一任务调度合并更新；不通过持续微任务扫描保活。用户会话标题、消息、账号 / 模型选项、Skill 正文和自有元数据排除在自动文案翻译之外。

本轮没有实际登录订阅账户、调用真实模型、连接串口或写入固件。安装页读取实际固件清单，并明确 `diagnostic-framework` 尚未启用控制，不把清单可读当作手机控制已经可用。
