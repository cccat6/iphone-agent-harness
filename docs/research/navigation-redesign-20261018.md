# 会话与设置导航重设计

本轮以操作目的重新划分入口，固件与蓝牙实现未改。

| 目的 | 入口与行为 |
| --- | --- |
| 查看已有会话 | 首页列表；点击会话进入内容，返回保留列表位置 |
| 开始新会话 | 底部唯一主按钮；设备未就绪时进入连接引导 |
| 查看/管理设备 | 会话标题旁的状态按钮；不再单独占一行 |
| 搜索会话 | 默认隐藏；在列表顶端下拉或点击搜索图标展开；取消清空并收起 |
| 技能管理 | 设置 → 技能；会话输入区仍有快捷入口 |
| 配置模型/工具 | 设置目录 → 账号或 API / MCP；独立页面有返回按钮 |
| 归档与导入 | 设置目录中的明确文字入口；删除首页三个点 |

下拉从空白或已有会话行均可触发；只在列表顶端、单指、明确向下超过阈值后释放时展开，不自动打开键盘。成功下拉派生的一次点击被忽略，防止误开会话；新的普通点按不受影响。取消触摸、横向、多指以及非列表控件不触发。

设置页使用导航代次，关闭或选择别的页面后，晚到的读取不会重新打开旧页。上下文保存反馈绑定原表单；账号保存、删除及归档读取完成后，不抢回用户已切换到的新页面。搜索同样只展示最新查询返回的结果。
