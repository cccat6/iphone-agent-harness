# Start using Harness

[简体中文](zh-Hans.md) · [Complete guide](../guide/README.md) · [Open Harness](https://igent.cc/)

1. **Set up the bridge.** Open the [browser installer](https://igent.cc/flash) on your computer, install the firmware and save your Wi-Fi network. Keep the phone and bridge on the same network.
2. **Connect your phone.** Pair **iPhone Agent Bridge** in Bluetooth settings and enable AssistiveTouch. In Harness, obtain the bridge information, connect and select your phone. The input test is optional. With two phones on the bridge, test each to confirm that its Harness page controls that phone.
3. **Choose a model.** Under **Settings → Accounts or API**, add an API endpoint and key or sign in to ChatGPT. Fetch the model list and choose a model.
4. **Give it a task.** Open a conversation, describe what you want and allow screen sharing. Keep the phone unlocked while the agent works. Stopping sharing pauses the task; **Continue** starts sharing again.
5. **See the result.** The agent checks the outcome and returns to Harness. Change **Settings → Task completion** to leave it in the target app instead.

## Everyday use

- Switch the session-list title between active conversations and **Archived**. Swipe a row to rename, archive, restore or delete it.
- Read earlier messages while keeping your position. **Latest** returns to the newest reply.
- Export a conversation from its menu and import it in Settings. Exports include messages and images, up to 64 MiB.
- Add the [clipboard Shortcut](https://igent.cc/shortcuts/clipboard.html) for long or multilingual text.
- Browse, create and share [skills](https://igent.cc/skills). Skill and creator-identity imports support files up to 10 MiB.
