# 手机使用与验收

[English](README.md) · [打开 Harness](https://igent.cc/) · [项目首页](../../README.md)

在 iPhone 或 iPad 的 Safari 中使用。Harness 在一个页面里连接 ESP32 桥、共享屏幕和执行任务；设备管理页面只在首次设置或修改配置时使用，不需要一直开着。

## 按顺序检查这八步

1. **连接 ESP32 桥。** 手机和桥连到同一个 Wi-Fi。首次使用电脑烧录页提供的连接链接，或在手机打开 `http://igent.local/settings`，点“返回 Harness”导入连接信息。之后在“设置 → 设备”点“连接 ESP32 桥”；已经配过 Wi-Fi 的板子不用再配网。

2. **确认手机输入。** 在 iOS 蓝牙设置中配对 **iPhone Agent Bridge**，按教程开启辅助触控。回到 Harness 点“开始测试”，等桥自动输入八位数字后确认。全键盘控制开或关都可以；这里不需要手动填写连接码。

3. **添加账号或 API，开始对话。** 在“设置 → 账号或 API”添加连接，填写 API 端点和密钥并获取模型列表，或按界面登录 ChatGPT。新建会话、选择模型并发送一条消息；再打开设置应能看到刚保存的连接。填写表单或搜索会话时，键盘不应遮住返回、关闭和输入区域。

4. **共享屏幕并执行任务。** 先用时钟或专门的测试页面，开始屏幕共享，再让 AI 完成一次点按、滚动或拖动。切到目标 App 观察实际动作，返回会话查看截图和结果。计划模式用于观察和安排步骤，任务模式才执行操作。

5. **试一次长文本。** 打开[剪贴板教程](https://igent.cc/shortcuts/clipboard.html)，下载并添加 **iPhone Agent Clipboard**，保留这个名称。让 Harness 准备一段中英文测试文字，点“用快捷指令复制”，完成系统询问后返回；任务应等到复制确认，再检查输入框并粘贴。也可以回到网页点“复制并继续”，验证直接复制。没有待复制文字时单独运行快捷指令，应直接结束并保留原剪贴板。

6. **保存和找回会话。** 给测试会话改名、置顶，再归档并从“设置 → 查看归档”找回。会话菜单可“导出为文件”，“设置 → 从文件导入会话”可导入为新会话。检查消息和图片是否完整；列表顶部下拉或点搜索图标可以搜索会话。长会话向上滚动时逐页加载，图片进入屏幕才读取；横竖屏切换和放大后，输入框、返回及关闭按钮应仍可见。

7. **使用技能和 MCP。** 在“设置 → 技能”添加一个社区技能，或让 Harness 创建并修改自己的技能；下载的社区技能保持只读。若已有 MCP 服务，在“设置 → MCP 服务器”添加它，选择工具后试一个只读操作。返回设置时，服务器、访问令牌和工具选择应保留。

8. **停止、断开和恢复。** 任务进行中点停止，确认手机不再继续动作。断开桥后，会话应显示“ESP32 桥未连接”；AI 可以继续交谈，但不能发送手机操作，并能说明缺少设备。重新连接并再次完成输入测试后，再恢复控制。

## 日常设置

会话消息和图片自动保存在当前浏览器，导出文件不包含登录凭据或 API 密钥。网站进入时会尝试申请保留本地数据；尚未获准时，可在“设置 → 设备上的数据”重试。

会话文件导入、导出上限为 **64 MiB**，包括图片；达到导出上限不会删除原会话。技能与创作者身份文件的导入上限为 **10 MiB**。换设备前可在“创作者身份”导出加密备份，以便恢复自己发布技能的归属。

“设置 → 上下文与图片”提供自动压缩阈值，默认 **750,000 token**。完整历史保留在本地。图片不裁剪、不缩小尺寸，以 JPEG 保存，质量分为“节省空间”“均衡”“高清”。

设备名在 `http://igent.local/settings` 修改；改名后使用新地址。HTTP 还用于配网和快捷指令取件，日常控制通过 WebRTC Direct 完成。项目提供统一通信证书配置，无需手机安装证书或为每块板子维护证书。

当前手机原型已有前台和录屏后台短测成功记录，也出现过抖动；正式 RTC 与蓝牙组合固件、快捷指令导入和完整手机闭环正在验收。[连接记录](../architecture/lan-connection.md)会区分这些结果。
