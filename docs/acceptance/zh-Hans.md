# 手机使用与验收

[English](README.md) · [打开 Harness](https://igent.cc/) · [项目首页](../../README.md)

在 iPhone 或 iPad 的 Safari 中使用。Harness 在一个页面里连接 ESP32 桥、共享屏幕和执行任务；设备管理页面只在首次设置或修改配置时使用，不需要一直开着。

## 按顺序检查这八步

1. **获取信息并连接 ESP32 桥。** 手机和桥连到同一个 Wi-Fi。进入 Harness 的设备页面，首次先点“获取桥的信息”，读取成功后点“返回设备连接”，再点“连接 ESP32 桥”。获取的信息会先保存在当前浏览器；已完成的第一步会继续显示，标记信息已保存。电脑烧录页提供的设备链接也可以导入信息，已经配过 Wi-Fi 的板子不用再配网。

2. **配对手机。** 在 iOS 蓝牙设置中配对 **iPhone Agent Bridge**，按教程开启辅助触控。回到 Harness 选择已连接的手机，显示就绪后即可新建会话和操作。“开始测试”的八位数字输入是可选检查，需要确认实际输入时再做。全键盘控制开或关都可以；不需要手填连接码。旧固件可能仍需可选的旧版测试或更新，测试不可用时不能显示通过。

3. **添加账号或 API，开始对话。** 在“设置 → 账号或 API”添加连接，填写 API 端点和密钥并获取模型列表，默认模型可下拉选择或手动输入，所有获取到的模型都可切换；也可按界面登录 ChatGPT。凭据直接保存在浏览器，不再要求加密口令。新建会话、选择模型及可用的推理强度，再发送一条消息；首条请求成功后应自动更新会话名称，手动重命名后不应被自动标题覆盖。再打开设置应能看到刚保存的连接。填写表单或搜索会话时，键盘不应遮住返回、关闭和输入区域。

4. **共享屏幕并执行任务。** 先用时钟或专门的测试页面，开始屏幕共享，再让 AI 完成一次点按、滚动或拖动。切到目标 App 观察实际动作，返回会话查看截图和结果。不需要切换模式：问“能不能”会先回答；要求制定计划会显示计划卡片，由你点“执行计划”；明确要求操作时才执行。未共享屏幕时，发送消息会请求共享。任务中结束共享应暂停，点“共享屏幕并继续”重新授权后，应先查看新屏幕再继续。

5. **先试精确控件，再试长文本。** 在时钟中要求设置一个无风险的具体时间。支持数字编辑时应优先输入；不支持时小幅调整，等转轮停稳，保存前核对准确值。点偏或滑过头后应改变方法，不盲目重复。然后试长文本。 打开[剪贴板教程](https://igent.cc/shortcuts/clipboard.html)，下载并添加 **iPhone Agent Clipboard**，保留这个名称。让 Harness 准备一段中英文测试文字，点“用快捷指令复制”，完成系统询问后返回；任务应等到复制确认，再检查输入框并粘贴。也可以回到网页点“复制并继续”，验证直接复制。没有待复制文字时单独运行快捷指令，应直接结束并保留原剪贴板。

6. **保存和找回会话。** 左滑普通会话应出现“重命名”“归档”；在“设置 → 查看归档”左滑归档会话，应出现“重命名”“取消归档”“删除”，删除前要确认。置顶仍可从会话菜单操作。会话菜单可“导出为文件”，“设置 → 从文件导入会话”可导入为新会话。检查消息、计划卡片和图片是否完整；截图应显示为缩略图，点击才放大。普通界面不应出现工具 JSON，“设置 → 开发者模式”可显示详细信息。列表顶部下拉或点搜索图标可以搜索会话。长会话向上滚动时逐页加载，图片进入屏幕才读取；阅读旧消息时，新回复不应把页面拉到底部，点“回到最新”才回到最新位置；横竖屏切换和放大后，输入框、返回及关闭按钮应仍可见。

7. **使用技能和 MCP。** 在“设置 → 技能”添加一个社区技能，或让 Harness 创建并修改自己的技能；下载的社区技能保持只读。若已有 MCP 服务，在“设置 → MCP 服务器”添加它，选择工具后试一个只读操作。返回设置时，服务器、访问令牌和工具选择应保留。

8. **停止、断开和恢复。** 任务进行中点停止，确认手机不再继续动作。断开桥后，会话应显示“ESP32 桥未连接”；AI 可以继续交谈，但不能发送手机操作，并能说明缺少设备。重新连接、选择已就绪手机后恢复；仅在需要检查或旧固件要求时再做可选输入测试。站内进入设置、子页面、主页，并通过返回／前进回到原会话时，不应主动断开桥或结束共享；返回应逐级回到对应父页面。刷新或真正离开文档仍需重新授权录屏。

默认不按整项任务的固定时长或步数提前结束。点停止立即结束，失去共享则暂停；每个动作计划仍有短时安全限制，后续工作依靠新观察和新计划继续。这不代表 iOS 会让 Safari 无限后台运行。

## 日常设置

会话消息和图片自动保存在当前浏览器，导出文件不包含登录凭据或 API 密钥。网站进入时会尝试申请保留本地数据；尚未获准时，可在“设置 → 设备上的数据”重试。

会话文件导入、导出上限为 **64 MiB**，包括图片；达到导出上限不会删除原会话。技能与创作者身份文件的导入上限为 **10 MiB**。换设备前可在“创作者身份”导出加密备份，以便恢复自己发布技能的归属。

“设置 → 上下文与图片”提供自动压缩阈值，默认 **750,000 token**。完整历史保留在本地。图片不裁剪、不缩小尺寸，以 JPEG 保存，质量分为“节省空间”“均衡”“高清”。

设备名在 `http://igent.local/settings` 修改；改名后使用新地址。HTTP 还用于配网和快捷指令取件，日常控制通过 WebRTC Direct 完成。项目提供统一通信证书配置，无需手机安装证书或为每块板子维护证书。

当前手机原型已有前台和录屏后台短测成功记录，也出现过抖动；四类固件已由源码 `d6d8f75211fd14b8aa57d3f5ebf0f32d7fa425fe4f588df263a4eeb62a4b244a` 编译完成；当前授权 USB 设备未连接，这一候选版尚未刷写或实机验证。快捷指令导入和完整手机闭环仍待真机验收。[连接记录](../architecture/lan-connection.md)会区分这些结果。
