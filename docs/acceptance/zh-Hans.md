# 使用说明

[English](README.md) · [网站](https://igent.cc) · [项目首页](../../README.md)

在 iPhone 或 iPad 的 Safari 中打开网站，默认进入会话列表。顶部的主页按钮打开项目介绍；主页顶部的“打开 Harness”可以返回会话。电脑端提供项目介绍、技能社区和 ESP32 烧录页面。

会话页的设备状态与标题在同一行，底部只有“新会话”。搜索默认隐藏：在列表顶端往下拉，或点击搜索图标即可展开；点击“取消”会清空筛选并收起搜索。设置采用目录，进入某项后可返回上一级，关闭则回到原页面。

## 开始对话

打开“设置 → 账号或 API”，选择“添加账号或 API”。使用 ChatGPT 时，选择 ChatGPT 账号并按页面提示登录；使用 API 时，选择 OpenAI 或 Anthropic 兼容接口，填写服务商提供的 **API 端点**和密钥，获取模型列表并保存。也可以手动填写模型 ID。

点击“新会话”，在底部选择模型，然后发送消息。模型选择器可以切换不同账号、API 和模型。“对话”用于交流，“计划”用于观察和安排步骤，“任务”用于执行操作。操作手机需要设备连接和屏幕共享；未连接设备或尚未完成连接测试时，点击新会话会进入设备设置；已有会话仍可查看。ChatGPT 订阅的真实 Safari 登录仍在验证中。

## 会话与备份

消息和图片自动保存在当前浏览器。会话右上角的菜单提供重命名、置顶、归档、删除和“导出为文件”；“设置 → 从文件导入会话”可以恢复备份；“设置 → 查看归档”可以查看归档会话。导入文件会创建一个单独的会话。

网站首次进入时会尝试向浏览器申请保留数据，浏览器可能自行决定而不显示提示。如果尚未获准，可以在“设置 → 设备上的数据”重试。需要备份时直接导出会话；登录信息和 API 密钥不包含在会话备份中。

## 上下文与图片

“设置 → 上下文与图片”中，自动压缩的默认阈值为 **750,000 token**。达到阈值时，当前模型会总结较早的消息，完整会话仍保存在设备上。如果模型支持的上下文较短，也会在遇到长度限制时尝试压缩。

图片保留原始尺寸，以 JPEG 压缩保存。质量可选择“节省空间”“均衡”或“高清”，用于之后保存的图片。

## 技能

在“设置 → 技能”中查看已保存的技能，或进入社区添加技能。官网使用固定的社区地址，无需设置 API。添加的技能保存在当前浏览器，可以启用、停用或检查更新。

可以手动创建自己的技能，也可以让 Harness 通过对话协助编写和修改。自己创建的技能可以编辑、导出或发布到社区；下载的社区技能保持只读。换设备前，可以在“创作者身份”中导出加密备份，之后恢复自己的技能归属。

## MCP 工具

在“设置 → MCP 服务器”中添加服务器，填写名称、MCP 端点和可选的访问令牌，点击“保存并连接”。连接后选择需要使用的工具并启用。可以添加多个服务器，在任务模式中使用它们。

当前支持 Streamable HTTP。服务器、访问令牌和工具选择保存在当前浏览器，刷新后自动重新连接。服务器以折叠列表显示，点击可编辑；断开连接保留设置，删除服务器才会移除本地凭据。

## 手机与 ESP32

1. 在电脑的烧录页面安装当前固件，点击“读取设备信息”，保存设备的 Wi-Fi 名称、密码和手机设置链接。
2. 手机连接设备的 Wi-Fi，打开 `http://192.168.4.1`，填写家里的 Wi-Fi 名称和密码。等页面确认连接成功，再切回家里的 Wi-Fi；填写错误时可以直接重试。
3. 在手机打开设置链接，点击“连接”。连接信息自动保存在当前浏览器，之后无须重填连接码，也不需要设置解锁密码。设备连接标签页打开后，切回 Harness，**保持设备连接标签页打开**。不需要安装证书。
4. 在手机蓝牙设置中与 **iPhone Agent Bridge** 配对，然后回到 Harness 选择这台手机，点击“开始测试”。设备会自动输入八位数字，收到后点击确认。
5. 按设置教程开启“辅助触控”，返回 Harness 开始共享屏幕。全键盘控制不作为连接条件，无须关闭或勾选确认框。之后可以在“任务”模式中操作手机。

操作指令在手机和 ESP32 之间通过局域网传输，网站服务器不转发。关闭设备连接标签页会断开连接；重新连接后，需要再次完成手机连接测试。

Safari 27.0.1 真机已经通过五轮 GET／POST 请求，包含录屏期间两个标签页都在后台的情况；这五轮网络请求覆盖约 21 秒。无限后台运行、完整手机操作和所有网络环境仍不能据此视为已验收。具体证据见[局域网连接说明](../architecture/lan-connection.md)。
