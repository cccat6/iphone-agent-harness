# 手机使用指南

[English](README.md) · [打开 Harness](https://igent.cc/) · [项目首页](../../README.md)

使用 iOS/iPadOS 27 或以上的 Safari，先试无风险的小任务，保持手机解锁。团队或安装器负责固件准备，你不需要构建软件或查看诊断日志。

## 五步开始

1. **准备桥接器。** 在电脑烧录页用可传数据的 USB 线连接支持的 ESP32 开发板，安装后读取信息，保留手机链接。新板子先连接设备设置 Wi-Fi，保存常用 2.4 GHz 网络，再让手机回到同一网络。
2. **连接手机。** 打开提供的链接，或在 Harness 点“获取桥的信息”，保存后返回，点“连接 ESP32 桥”。iOS 蓝牙配对 **iPhone Agent Bridge**，开启辅助触控，选择已就绪手机。新固件数字测试为可选检查，无需手填连接码、安装证书或长期保留辅助标签页。
3. **选择 AI。** 在“设置 → 账号或 API”填写端点／密钥并获取模型，或按界面登录 ChatGPT。默认模型可选择或输入；新建会话，选择模型和支持的推理强度。真实 Safari 订阅兼容性取决于服务，存在登录入口不代表登录一定可用。
4. **共享并提出短任务。** 开始共享屏幕，试测试闹钟或文字输入。问能力会收到说明，请求计划会显示可检查计划，明确要求操作时才执行。观察手机实际动作。停止会结束运行，失去共享则暂停；继续时重新共享并先观察新画面。
5. **核对完成结果。** AI 应先验证结果再结束，默认随后返回 Harness；希望停留目标 App 时，可关闭“设置 → 任务完成后 → 任务完成后返回 Harness”。重要结果请自己再确认。

## 使用时顺手检查

- **会话：**点列表标题的选择器切到“已归档”再切回。普通行左滑可改名／归档，归档行可改名／取消归档／删除，删除需确认。下拉列表或点搜索按钮查找。手动名称不应被自动标题覆盖。
- **阅读与备份：**回复到来时阅读旧消息，位置应保持；点“回到最新”才回到底部。会话菜单导出、设置导入，核对图片和消息，文件上限 64 MiB。浏览器可能清除本地数据，请备份重要会话。
- **精确输入：**在安全的时钟控件要求具体时间，支持数字编辑时应优先尝试，否则小幅调整并等停稳，保存前核对准确值。收到输入回执不等于画面已成功。
- **长文本：**从[剪贴板教程](https://igent.cc/shortcuts/clipboard.html)安装 **iPhone Agent Clipboard**，保留名称。点“用快捷指令复制”或前台“复制并继续”；确认复制、检查目标输入框后才粘贴。无待处理文字时，快捷指令应保留原剪贴板。
- **技能：**电脑或手机均可创作／修改无隐私自有技能，导出加密作者身份备份，需要时明确恢复。归属来自浏览器身份，不是 iOS UID。内置／下载项只读，刷新检查更新并保留开关；更新失败保留旧版。只发布你愿意公开的内容。
- **可选 MCP：**使用支持浏览器 CORS 的可访问 Streamable HTTP 服务，明确选工具，试只读操作；撤权后应拒绝。修改操作中断可能已有外部效果，核对后再重试。
- **恢复：**停止短任务、停共享、断开再连接桥，确认无后续误动作／卡键／卡指针，重新选择就绪目标。站内返回／前进保留本页连接和共享，真正刷新仍需重授权共享。

技能和创作者身份文件的导入上限为 10 MiB。

会话、图片、凭据在当前浏览器，导出不含凭据；选中内容仍会发送所用 AI／MCP 服务。换浏览器前，技能作者还需单独备份身份。上下文自动摘要默认 750,000 token，完整历史保留；JPEG 三档均保留图像尺寸。

任务默认没有整项时长／步数上限，每个动作计划仍有短时安全限制。Safari 可能暂停后台运行。手机手势、后台取屏、快捷指令及多手机仍属实验能力，需在具体设备检查。桥只有一个活动 WebRTC 连接；最新多客户端导入／注册修复已准备，仍待刷写和实机验证。
