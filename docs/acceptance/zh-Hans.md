# 开始使用 Harness

[English](README.md) · [完整教程](../guide/zh-Hans.md) · [打开 Harness](https://igent.cc/)

1. **准备桥接器。** 在电脑打开[网页烧录器](https://igent.cc/flash)，安装固件并保存 Wi-Fi。手机和桥连接同一网络。
2. **连接手机。** 在蓝牙设置中配对 **iPhone Agent Bridge**，开启辅助触控。在 Harness 获取桥的信息、连接并选择手机。输入测试可按需运行。两台手机连接同一个 ESP32 桥时，建议分别测试，确认各自网页控制对应手机。
3. **选择模型。** 在“设置 → 账号或 API”添加 API 端点和密钥，或登录 ChatGPT，获取模型列表后选择模型。
4. **提出任务。** 打开会话，描述需求并允许屏幕共享。操作期间保持手机解锁。停止共享会暂停任务，点击“继续”可重新开始共享。
5. **查看结果。** 智能体核对结果后返回 Harness。希望它停留在目标 App，可修改“设置 → 任务完成后”。

## 日常使用

- 点击会话列表标题，切换当前会话与“已归档”。左滑会话行可重命名、归档、恢复或删除。
- 向上阅读历史消息时保持原位置；点击“回到最新”查看最新回复。
- 在会话菜单导出，在设置中导入。文件包含消息和图片，上限为 64 MiB。
- 安装[剪贴板快捷指令](https://igent.cc/shortcuts/clipboard.html)，用于输入长文本或多语言文字。
- 在[技能社区](https://igent.cc/skills)浏览、创作和分享技能。技能和创作者身份导入文件上限为 10 MiB。
